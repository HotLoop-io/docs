# docs.hotloop.io

Source for HotLoop's documentation site, published via GitHub Pages at [docs.hotloop.io](https://docs.hotloop.io).

Plain static HTML and CSS, no build step. Edit the `.html` files directly and push to `main` to deploy.

- `index.html`, the docs home
- `getting-started.html`, the install and first-loop walkthrough (a placeholder until the product source lands)
- `licensing.html`, the full license text and a plain language summary
- `assets/`, the shared stylesheet and logo
