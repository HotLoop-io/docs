# docs.hotloop.io

Source for HotLoop's documentation site, published via GitHub Pages at [docs.hotloop.io](https://docs.hotloop.io).

Plain static HTML/CSS, no build step — edit the `.html` files directly and push to `main` to deploy.

- `index.html` — docs home
- `getting-started.html` — install & first-loop walkthrough (placeholder until product source lands)
- `licensing.html` — full license text + summary
- `assets/` — shared stylesheet and logo

See [`HotLoop-io/HotLoop-io`](https://github.com/HotLoop-io/HotLoop-io) for the org overview and canonical LICENSE.
