HotLoop for CODESYS is HotLoop beside a CODESYS runtime. EmberNet packages and deploys it from the App Store, and the EmberNet docs cover that side.

Where it is on the EmberNet docs:

- [HotLoop for CODESYS on EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-codesys)
- [App Store Overview](https://docs.embernet.ai/docs/app-store/overview)
- [HotLoop Gateway on EmberNet](https://docs.embernet.ai/docs/app-store/hotloop)
- [HotLoop Edge on EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-edge)

The Gateway page also covers HotLoop Transmitter, the CODESYS library that publishes OPC UA PubSub.

Back to the [HotLoop for CODESYS overview](/codesys/overview/), or the [HotLoop for CODESYS page on hotloop.io](https://hotloop.io/codesys/).
