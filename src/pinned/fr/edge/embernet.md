HotLoop Edge, c'est IoT plus un serveur OPC UA et la publication Sparkplug B avec stockage et retransmission. EmberNet le package et le déploie depuis l'App Store, et la documentation EmberNet couvre cet aspect.

Où le trouver dans la documentation EmberNet :

- [HotLoop Edge sur EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-edge)
- [Vue d'ensemble de l'App Store](https://docs.embernet.ai/docs/app-store/overview)
- [HotLoop Gateway sur EmberNet](https://docs.embernet.ai/docs/app-store/hotloop)
- [HotLoop IoT sur EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-iot)
- [HotLoop Edge Relay sur EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-edge-relay)
- [FUXA sur EmberNet](https://docs.embernet.ai/docs/app-store/fuxa)
- [HotLoop for CODESYS sur EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-codesys)

FUXA lit un Edge en OPC UA, et HotLoop for CODESYS l'installe à côté d'un runtime.
