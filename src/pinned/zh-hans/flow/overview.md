**为工厂接线，像审阅代码一样审阅它。**

HotLoop Flow 是面向工厂现场的可视化流程引擎，用 Go 编写。您在画布上把传感器、代理、PLC 和数据库连接起来，它在一个小到能放进 Pi 的静态二进制文件里运行这些连线，调度器不会因为传感器说话比读取它的一方更快而垮掉。

在糟糕的夜晚，这意味着：

- **每个队列都有上限，放不下的每条消息都会被计数。** 慢速历史数据库前面的快速传感器会按您选定的策略积压、阻塞或丢弃，这会先出现在图表上，而不是以日志里空无一物的 OOM kill 的形式出现。
- **历史数据库停机一小时，不会让您损失一小时。** 把连线标记为持久，当后面的节点不再接收消息时，消息会按顺序写入磁盘，`kill -9` 之后依然在。运行正常时，不会写入任何内容。[存储并转发](/zh-hans/flow/store-and-forward/)已针对一个停止了十分钟的真实 InfluxDB 验证过。
- **每个节点各自运行。** 每个节点一个 goroutine，所以处理大负载的 Function 节点只占用一个核心，不会拖累编辑器和这台机器上的其他所有流程。
- **流程文件可以审阅。** 它按字节原样加载和保存，修改一个属性就是一行 diff，每次保存都是原子的，并留有三份备份。每次部署都是[一条记录](/zh-hans/flow/deploys/)：谁、何时、为何，以及确切的字节，任意两条记录都可以在 API、命令行和 `git diff` 中[逐节点比较](/zh-hans/flow/deploys/#the-diff-reads-like-a-review)。任何一条都可以[回滚](/zh-hans/flow/deploys/#put-it-back)，凭据也包括在内。
- **不会在未加锁时启动。** 没有身份验证是启动错误，而不是默认值。`exec` 节点出厂时是关闭的，文件节点被限制在数据目录内，凭据使用 Argon2id 密钥下的 AES-256-GCM 加密。

它也能原样运行您现有的流程。这部分在[后面](/zh-hans/flow/migrating-from-node-red/)，因为它是一项功能，不是重点。

当前版本是 `{{flow}}`。镜像是适用于 amd64 的 `ghcr.io/hotloop-io/hotloop-flow:{{flow}}`（arm64 随下一个补丁版本提供），Helm 仓库是 `https://hotloop.io/hotloop-flow/`，[部署 Flow](/zh-hans/flow/deploying/)涵盖 Kubernetes、Podman 和 Quadlet。它有 117 种消息节点类型和 39 种 FlowLab 图表节点类型。家庭和实验室使用免费，学校、非营利组织和政府机构使用同样免费，通过合作伙伴平台 EmberNet 使用，包括商业使用，不受限制，遵循 HotLoop Source License Agreement。

## 数据

只给绝对数值，方便您在自己的硬件上核对。每项运行三次，打印的是范围。

| 指标 | 结果 |
|---|---|
| 二进制文件，linux/amd64，静态 | **41.7 MB** |
| 镜像，amd64 | **45.64 MB** |
| 从启动到响应第一个请求 | **0.05 s** |
| RSS，空闲 | **16.4 至 16.7 MiB** |
| RSS，下方 HTTP 负载下的峰值 | **26.4 至 28.5 MiB** |
| HTTP，五节点流程，8 个连接 | **13.0k 至 15.3k req/s** |
| HTTP 延迟 p50 / p99 | **0.39 至 0.41 ms / 1.78 至 4.03 ms** |
| 引擎，五节点链，无 I/O | **每条消息 2.20 至 3.11 µs**，分配 3.9 KB |

请明白这些数字不是什么。HTTP 数字特意穿过整个 HTTP 栈，因为这是您流程的客户端所看到的。而在饱和时，每个运行时都会排队，排队决定了尾部，所以不同次运行之间 p99 的波动比 p50 更大。

### 在 Raspberry Pi 5 上

同样的流程、同样的命令，2026-10-22，在一块 Raspberry Pi 5 Model B（8 GB，四个 Cortex-A76 核心）上，时钟限制在 2.0 GHz，以 Pod 方式运行已发布的 arm64 镜像 `2.2.0`，节点上除集群的 DaemonSet 外没有其他东西。运行三次，打印的是范围。

| 指标 | 结果 |
|---|---|
| 从启动到响应第一个请求 | **0.10 至 0.46 s** |
| RSS，空闲 | **88.0 至 88.3 MiB** |
| RSS，HTTP 负载下的峰值 | **40.3 至 40.5 MiB** |
| HTTP，五节点流程，8 个连接，30 s | **13.2k 至 13.4k req/s** |
| HTTP 延迟 p50 / p99 | **0.48 ms / 2.72 至 2.78 ms** |
| 引擎，五节点链，无 I/O | **每条消息 7.74 至 8.15 µs**，分配 4.0 KB |
| HTTP，同一条命令持续 600 s | **11.4k req/s**，p50 0.58 ms，p99 3.00 ms |

对于一直处于负载下的机器，最后一行才是实话。电路板不到一分钟就触及软温度上限，大约两分钟后开始降频，其余时间保持在 83 至 86 C，时钟 1.5 至 1.7 GHz。[基准测试页面](/zh-hans/flow/benchmarks/#raspberry-pi-5-上的结果)有完整的 Pi 运行记录。
