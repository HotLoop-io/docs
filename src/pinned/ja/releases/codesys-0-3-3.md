## 変更点

0.3.3 は 2026-11-15 に `{{codesysChartRepo}}` のインデックスに公開されました。provisioner は 0.3.2 が実行していたものと同じです。

- **HotLoop 4.20.0 をラップします。** 新しい Web UI は `/` のページで、エージェントは読めるものすべてを、書き込みゲートの内側で MCP を通じて変更できます。

これが意味すること:0.3.3 のボックスは、チャートのアップグレードだけで新しい UI と MCP ツールを得られ、ほかには何も要りません。

## 確認したこと

0.3.1 から、プロファイルを適用した 0.3.3 へのアップグレード。CODESYS Control for Linux SL 4.22.0.0 ランタイムの隣で:4.20.0 の新しいポッドが起動し、デバイスとその 2232 個のタグはそのまま残り、リスナーは再接続しました。ベアメタルで実行しました(2026-11-17)。
