HotLoop Edge は、IoT に OPC UA サーバーと、蓄積転送付きの Sparkplug B 発行を加えたものです。EmberNet が App Store からパッケージ化して展開し、その部分は EmberNet ドキュメントで説明しています。

EmberNet ドキュメントでの掲載場所です。

- [EmberNet の HotLoop Edge](https://docs.embernet.ai/docs/app-store/hotloop-edge)
- [App Store 概要](https://docs.embernet.ai/docs/app-store/overview)
- [EmberNet の HotLoop Gateway](https://docs.embernet.ai/docs/app-store/hotloop)
- [EmberNet の HotLoop IoT](https://docs.embernet.ai/docs/app-store/hotloop-iot)
- [EmberNet の HotLoop Edge Relay](https://docs.embernet.ai/docs/app-store/hotloop-edge-relay)
- [EmberNet の FUXA](https://docs.embernet.ai/docs/app-store/fuxa)
- [EmberNet の HotLoop for CODESYS](https://docs.embernet.ai/docs/app-store/hotloop-codesys)

FUXA は OPC UA 経由で Edge を読み取り、HotLoop for CODESYS はランタイムの隣に Edge をインストールします。

[企業での HotLoop の利用](/ja/business/)では、ライセンスと連絡方法を説明しています。

[HotLoop Edge の概要](/ja/edge/overview/)に戻るか、[hotloop.io の HotLoop Edge ページ](https://hotloop.io/edge/)へ進んでください。
