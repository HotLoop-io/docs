## Τι άλλαξε

Το 0.3.3 είναι στο ευρετήριο `{{codesysChartRepo}}`, δημοσιευμένο στις 2026-11-15. Ο provisioner είναι ο ίδιος που εκτελούσε το 0.3.2.

- **Περιβάλλει το HotLoop 4.20.0.** Το νέο web UI είναι η σελίδα στο `/`, και ένας πράκτορας μπορεί να αλλάξει μέσω MCP ό,τι μπορεί να διαβάσει, πίσω από την πύλη εγγραφής.

Τι σημαίνει αυτό για εσάς: ένα κουτί στο 0.3.3 παίρνει το νέο UI και τα εργαλεία MCP με μια αναβάθμιση chart και τίποτε άλλο.

## Τι ελέγχθηκε

Μια αναβάθμιση από το 0.3.1 με προφίλ εφαρμοσμένο στο 0.3.3, δίπλα σε runtime CODESYS Control for Linux SL 4.22.0.0: ένα νέο pod στο 4.20.0 ανέβηκε, οι συσκευές και τα 2232 tags τους ήταν ακόμη εκεί, και οι ακροατές συνδέθηκαν ξανά. Έχει εκτελεστεί σε bare metal (2026-11-17).
