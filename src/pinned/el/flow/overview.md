**Καλωδιώστε το εργοστάσιο. Ελέγξτε το όπως κώδικα.**

Το HotLoop Flow είναι μια οπτική μηχανή ροών για το εργοστάσιο, γραμμένη σε Go. Συνδέετε αισθητήρες, brokers, PLC και βάσεις δεδομένων σε έναν καμβά, και εκείνη εκτελεί αυτές τις συνδέσεις σε ένα στατικό δυαδικό αρκετά μικρό για ένα Pi, με έναν χρονοπρογραμματιστή που δεν καταρρέει όταν ένας αισθητήρας αρχίζει να μιλά πιο γρήγορα από ό,τι τον διαβάζει.

Τι σημαίνει αυτό μια δύσκολη νύχτα:

- **Κάθε ουρά έχει όριο, και κάθε μήνυμα που δεν χωράει καταμετράται.** Ένας γρήγορος αισθητήρας μπροστά από ένα αργό historian συσσωρεύεται, μπλοκάρει ή απορρίπτει σύμφωνα με την πολιτική που επιλέξατε, και φαίνεται σε ένα γράφημα πριν φανεί ως OOM kill χωρίς τίποτα στο αρχείο καταγραφής.
- **Ένα historian που πέφτει για μία ώρα δεν σας κοστίζει μία ώρα.** Σημειώστε μια σύνδεση ως ανθεκτική και όταν ο κόμβος πίσω της σταματήσει να δέχεται μηνύματα, αυτά πηγαίνουν στον δίσκο με τη σειρά και είναι ακόμη εκεί μετά από ένα `kill -9`. Όσο όλα είναι υγιή, δεν γράφεται τίποτα. Η [Αποθήκευση και προώθηση](/el/flow/store-and-forward/) δοκιμάστηκε απέναντι σε ένα πραγματικό InfluxDB που ήταν σταματημένο για δέκα λεπτά.
- **Κάθε κόμβος τρέχει μόνος του.** Μία goroutine ανά κόμβο, ώστε ένας κόμβος Function που επεξεργάζεται ένα μεγάλο φορτίο να σας κοστίζει έναν πυρήνα, όχι τον επεξεργαστή και όλες τις άλλες ροές του μηχανήματος.
- **Το αρχείο της ροής μπορεί να ελεγχθεί.** Φορτώνεται και αποθηκεύεται byte προς byte, η αλλαγή μίας ιδιότητας είναι ένα diff μίας γραμμής, και κάθε αποθήκευση είναι ατομική με τρία αντίγραφα ασφαλείας πίσω της. Κάθε ανάπτυξη είναι [μια εγγραφή](/el/flow/deploys/): ποιος, πότε, γιατί και τα ακριβή bytes, και οποιεσδήποτε δύο από αυτές [συγκρίνονται κόμβο προς κόμβο](/el/flow/deploys/#η-διαφορά-διαβάζεται-σαν-αναθεώρηση), στο API, στη γραμμή εντολών και μέσα στο `git diff`. Οποιαδήποτε από αυτές [επαναφέρεται](/el/flow/deploys/#βάλτε-το-πίσω), μαζί με τα διαπιστευτήρια.
- **Δεν ξεκινά ξεκλείδωτο.** Η απουσία ταυτοποίησης είναι σφάλμα εκκίνησης, όχι προεπιλογή. Ο κόμβος `exec` παραδίδεται απενεργοποιημένος, οι κόμβοι αρχείων περιορίζονται στον κατάλογο δεδομένων, και τα διαπιστευτήρια είναι AES-256-GCM κάτω από κλειδί Argon2id.

Εκτελεί επίσης τις υπάρχουσες ροές σας αυτούσιες. Αυτό είναι [πιο κάτω](/el/flow/migrating-from-node-red/), γιατί είναι δυνατότητα, όχι το κύριο.

Η τρέχουσα έκδοση είναι η `{{flow}}`. Η εικόνα είναι η `ghcr.io/hotloop-io/hotloop-flow:{{flow}}` για amd64 (το arm64 ακολουθεί στην επόμενη έκδοση διορθώσεων), το αποθετήριο Helm είναι `https://hotloop.io/hotloop-flow/`, και η [Ανάπτυξη του Flow](/el/flow/deploying/) καλύπτει Kubernetes, Podman και Quadlet. Έχει 117 τύπους κόμβων για μηνύματα και 39 για διαγράμματα FlowLab. Η οικιακή χρήση και η χρήση σε εργαστήριο είναι δωρεάν, όπως και η χρήση από σχολεία, μη κερδοσκοπικούς οργανισμούς και δημόσιους φορείς, και η χρήση μέσω του EmberNet, μιας συνεργαζόμενης πλατφόρμας, και η επαγγελματική, είναι χωρίς περιορισμούς, βάσει του HotLoop Source License Agreement.

## Οι αριθμοί

Μόνο απόλυτοι αριθμοί, ώστε να μπορείτε να τους ελέγξετε στο δικό σας υλικό. Τρεις εκτελέσεις ο καθένας, και τυπώνεται το εύρος.

| Μέτρηση | Αποτέλεσμα |
|---|---|
| Δυαδικό, linux/amd64, στατικό | **41.7 MB** |
| Εικόνα, amd64 | **45.64 MB** |
| Από την εκκίνηση έως το πρώτο αίτημα που απαντήθηκε | **0.05 s** |
| RSS, σε αδράνεια | **16.4 έως 16.7 MiB** |
| RSS, κορύφωση υπό το φορτίο HTTP παρακάτω | **26.4 έως 28.5 MiB** |
| HTTP, ροή πέντε κόμβων, 8 συνδέσεις | **13.0k έως 15.3k req/s** |
| Καθυστέρηση HTTP p50 / p99 | **0.39 έως 0.41 ms / 1.78 έως 4.03 ms** |
| Μηχανή, αλυσίδα πέντε κόμβων, χωρίς I/O | **2.20 έως 3.11 µs ανά μήνυμα**, 3.9 KB δεσμευμένα |

Να ξέρετε τι δεν είναι αυτοί οι αριθμοί. Ο αριθμός HTTP περνά επίτηδες από ολόκληρη τη στοίβα HTTP, γιατί αυτό βλέπει ένας πελάτης της ροής σας. Και υπό κορεσμό κάθε περιβάλλον εκτέλεσης βάζει σε ουρά και η ουρά κυριαρχεί στην ουρά της κατανομής, γι' αυτό το p99 κυμαίνεται περισσότερο από το p50 ανάμεσα στις εκτελέσεις.

### Σε Raspberry Pi 5

Η ίδια ροή και οι ίδιες εντολές, στις 2026-10-22, σε ένα Raspberry Pi 5 Model B (8 GB, τέσσερις πυρήνες Cortex-A76) με το ρολόι περιορισμένο στα 2.0 GHz, με τη δημοσιευμένη εικόνα arm64 `2.2.0` ως pod και τίποτα άλλο στον κόμβο εκτός από τα DaemonSets του συμπλέγματος. Τρεις εκτελέσεις, τυπώνεται το εύρος.

| Μέτρηση | Αποτέλεσμα |
|---|---|
| Από την εκκίνηση έως το πρώτο αίτημα που απαντήθηκε | **0.10 έως 0.46 s** |
| RSS, σε αδράνεια | **88.0 έως 88.3 MiB** |
| RSS, κορύφωση υπό το φορτίο HTTP | **40.3 έως 40.5 MiB** |
| HTTP, ροή πέντε κόμβων, 8 συνδέσεις, 30 s | **13.2k έως 13.4k req/s** |
| Καθυστέρηση HTTP p50 / p99 | **0.48 ms / 2.72 έως 2.78 ms** |
| Μηχανή, αλυσίδα πέντε κόμβων, χωρίς I/O | **7.74 έως 8.15 µs ανά μήνυμα**, 4.0 KB δεσμευμένα |
| HTTP, η ίδια εντολή για 600 s | **11.4k req/s**, p50 0.58 ms, p99 3.00 ms |

Η τελευταία γραμμή είναι η ειλικρινής για ένα μηχάνημα που μένει φορτωμένο. Η πλακέτα έφτασε το μαλακό όριο θερμοκρασίας σε λιγότερο από ένα λεπτό, άρχισε να μειώνει τη συχνότητα από το δεύτερο λεπτό περίπου και έμεινε στους 83 έως 86 C με το ρολόι στα 1.5 έως 1.7 GHz για το υπόλοιπο. Η [σελίδα των benchmarks](/el/flow/benchmarks/#αποτελέσματα-σε-raspberry-pi-5) έχει ολόκληρη την εκτέλεση στο Pi.

Η [σελίδα των benchmarks](/el/flow/benchmarks/) έχει τη μέθοδο και τις επιφυλάξεις.

Θα το χρησιμοποιήσετε σε εργοστάσιο; Το [Χρήση του HotLoop σε επιχείρηση](/el/business/) καλύπτει την άδεια χρήσης και πώς θα επικοινωνήσετε μαζί μας.
