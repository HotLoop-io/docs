HotLoop Edge is IoT plus an OPC UA server and Sparkplug B publishing with store and forward. EmberNet packages and deploys it from the App Store, and the EmberNet docs cover that side.

Where it is on the EmberNet docs:

- [HotLoop Edge on EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-edge)
- [App Store Overview](https://docs.embernet.ai/docs/app-store/overview)
- [HotLoop Gateway on EmberNet](https://docs.embernet.ai/docs/app-store/hotloop)
- [HotLoop IoT on EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-iot)
- [HotLoop Edge Relay on EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-edge-relay)
- [FUXA on EmberNet](https://docs.embernet.ai/docs/app-store/fuxa)
- [HotLoop for CODESYS on EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-codesys)

FUXA reads an Edge over OPC UA, and HotLoop for CODESYS installs it beside a runtime.

Back to the [HotLoop Edge overview](/edge/overview/), or the [HotLoop Edge page on hotloop.io](https://hotloop.io/edge/).
