## 바뀐 내용

0.3.10은 2026-11-23에 `{{codesysChartRepo}}` 인덱스에 게시되었습니다. 설치할 것은 이것이며, 0.3.9가 더한 것을 모두 담고 있습니다.

- **HotLoop 4.24.0을 감쌉니다.** CODESYS PLC 자체 알람을 알람 목록에 보여 주고 화면을 P&ID로 그립니다.
- **provisioner 0.4.1을 실행합니다.** 프로필이 화면 하나 외에 화면 목록도 받으므로, WebVisu 페이지가 여럿인 프로젝트가 온전히 되살아납니다.
- **예제 프로필이 바로 연결됩니다.** 태그가 OPC UA PubSub 필드 인덱스를 쓰므로, 만들어지는 장치가 연결을 재시도하지 않습니다.
- **차트는 Gotify와 Discord 알람 채널을 자격 증명이 생길 때까지 제외하므로,** 기본 설치에서 파드가 시작됩니다. 사용하려면 채널의 `enabled`를 true로 하고 토큰이나 URL을 설정하십시오.

이것이 의미하는 바: 이것을 설치하십시오. 0.3.8에서의 업그레이드는 장치와 태그를 그대로 유지합니다.

## 확인한 것

OPC UA PubSub 리스너 하나와 화면 둘의 프로필로 실제 클러스터의 인덱스에서 설치했습니다. provisioner가 장치, 태그 둘, 화면 둘을 수작업 없이 만들었고, 장치는 연결됨으로 읽혔으며, HotLoop 로그에 경고나 오류가 없었습니다. 두 파드를 삭제하자 장치가 설정된 채로 스스로 돌아왔고, [0.3.8](/ko/releases/codesys-0-3-8/)에서의 업그레이드는 장치와 태그를 유지했으며, 프로필 없는 설치는 HotLoop만 만들었습니다.

4.24.0 이미지는 amd64용으로 빌드되므로, arm64 노드에서는 HotLoop을 amd64 노드에 고정하세요.
