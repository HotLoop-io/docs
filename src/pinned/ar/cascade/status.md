1.5.1 هو الإصدار الصادر اليوم، وإصدارات 1.5.0 و1.4.2 و1.4.1 و1.4.0 و1.3.1 و1.3.0 و1.2.1 و1.2.0 و1.1.1 و1.1.0 و1.0.2 و1.0.1 و1.0.0 هي الثلاثة عشر التي سبقته. 1.0.0 هو الأول الذي يضم أعمال الهوية والحوكمة، وقد جُرّب كل جزء منها مقابل الخادم الحقيقي الذي يتعامل معه: SAML وLDAP وActive Directory وSCIM والأدوار المخصصة والأسرار الخارجية وبث السجلات والمتغيرات والمجلدات والتحليلات وتعليقات عمليات التشغيل وسياسات الإخفاء ومخازن blob على S3 وAzure. ويضم أيضًا محررًا جديدًا، فلكل واحدة من هذه الميزات شاشة. ويصلح 1.0.1 خطأ واحدًا في تسجيل الدخول: عندما تتعذر قراءة قاعدة البيانات كان Cascade يرد بـ "لم تسجّل الدخول" ويمسح ملف تعريف الارتباط، فيؤدي انقطاع قصير إلى تسجيل خروج الجميع وقد يحوّل عامل تحقق ثانيًا صحيحًا إلى رمز خاطئ. أما الآن فيطلب إعادة المحاولة ويحتفظ بالجلسة. ويتيح 1.0.2 لسير العمل أن يوقّع ويتحقق بمفتاح HMAC محفوظ كبيانات اعتماد، ولنموذج عام على موقع آخر أن يستدعي webhook من المتصفح. ويضيف 1.1.0 خادم MCP والشاشات التي كانت ناقصة في المحرر: بيانات الاعتماد والمشاريع والمستخدمين وسجل التدقيق والإعدادات وحسابك، وأصبح تسجيل الدخول صفحة المحرر نفسه. و1.1.1 هو 1.1.0 مع إضافة صورة arm64. ويمنح 1.2.0 خادم MCP أدواته الأربع الأخيرة، و1.2.1 هو 1.2.0 مع إضافة صورة arm64. ويجعل 1.3.0 المحرر متاحًا بالإنجليزية وثلاث عشرة لغة أخرى. و1.3.1 هو 1.3.0 مع إضافة صورة arm64. وينتظر 1.4.0 قاعدة البيانات عند البدء، ويحتفظ بعمليات التشغيل المنتهية للمدة التي تحددها وينظّف ملفاتها، ويمكنه تحديد عدد مرات استدعاء مفتاح API الواحد، ويجري النسخ الاحتياطي والاستعادة. ويصلح 1.4.1 أمرًا واحدًا في صفحة الإعدادات. ويمنح 1.4.2 صفحة تسجيل الدخول مظهرًا أنظف. ويتيح 1.5.0 للمالك حذف شخص من المستخدمين ومن API ومن خادم MCP. 1.5.1 هو 1.5.0 مع إضافة صورة arm64. ولا شيء يُنقل بين 1.0.0 و1.5.1.

ما ليس موجودًا بعد (التحكم في مصدر الكود عبر Git والبيئات، والمزيد من الموصلات، وخطوات الذكاء الاصطناعي) موجود في خارطة الطريق.

المستودع خاص. الصورة والـ chart عامّان ويُسحبان دون تسجيل دخول. الصورة هي `ghcr.io/hotloop-io/hotloop-cascade`، بالوسوم `1.5.1` و`1.4` و`1` و`latest` و`stable`، لمعماريتي amd64 وarm64.
