---
title: "Изграждане на Flow от изходния код"
description: "Изградете двоичния файл на Flow от изходния код: един статичен файл с редактора вътре и без C библиотека отдолу."
---

HotLoop Flow е един статичен двоичен файл с редактора вътре, така че повечето хора теглят публикувания образ и никога не изграждат нищо. Ако искате собствено изграждане, изходният код е публичен, а за изграждането са нужни Go и Node.

```bash
cd web && npm install && npm run build && cd ..
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o hotloop-flow ./cmd/hotloop-flow
```

Резултатът е статичен, без C библиотека отдолу, така че работи в distroless образ без нищо друго инсталирано. Всяка версия на Flow се изгражда от версионен таг и от нищо друго, така че образът във вашия цех винаги е такъв, който можете да назовете и да проследите до версия.
