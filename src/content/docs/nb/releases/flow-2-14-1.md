HotLoop Flow 2.14.1 er 2.14.0 med arm64-imaget lagt til, og ingenting annet. 2.14.0 kom bare for amd64 for å komme først i produksjon og stå som stabil, og dette er det ene lille steget som bygger begge. Ingenting endres i koden, chartet, innstillingene eller flowene dine.

## Hva som er endret

- Imaget bygges for linux/amd64 og linux/arm64. Taggene `2.14.1`, `2.14` og `2` inneholder begge.
- README og installasjonssidene nevner 2.14.1 og sier amd64 og arm64.

## Nye innstillinger

Ingen.

## Oppgradering

En enkel `helm upgrade` til 2.14.1-imaget og -charten, eller den nye taggen i Quadlet-enheten din. Hvis du er på arm64 og ble på 2.13.1 mens 2.14.0 bare var amd64, er dette ditt steg til resten av MCP-verktøyene og gruppetømmingen: les notatene for 2.14.0 for hva de er og hva som ikke er bevist. Ingenting skjer ved første oppstart, og ingenting må migreres.

Image: `ghcr.io/hotloop-io/hotloop-flow:2.14.1`, linux/amd64 og linux/arm64. Chart: `https://hotloop.io/hotloop-flow/`. README-en på denne taggen har resten, med bilder: https://github.com/HotLoop-io/hotloop-flow/blob/v2.14.1/README.md
