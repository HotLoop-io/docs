Dette er multi-arch-bygget av [4.22.0](/nb/releases/hotloop-4-22-0/). Produktkoden er den samme som 4.22.0 sin: panelsiden som fyller skjermen sin, Import from CODESYS på skjermen Alarms, delte OPC UA PubSub-sockets og HotLoop Free Use License 1.0. 4.22.0 var amd64-bygget, og `stable` beholdt arm-imagene det allerede hadde.

4.22.1 bygger hele settet: Gateway for amd64 og arm64, og Edge, IoT og Edge Relay for amd64, arm64 og arm/v7. Les [notatene for 4.22.0](/nb/releases/hotloop-4-22-0/) for alt som har endret seg siden 4.21.1.

- Alle fire chartene (`hotloop`, `hotloop-iot`, `hotloop-edge`, `hotloop-edge-relay`) er på 4.22.1, med hver tidligere versjon fortsatt i indeksen.
