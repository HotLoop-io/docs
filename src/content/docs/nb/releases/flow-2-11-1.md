HotLoop Flow 2.11.1 er 2.11.0 med arm64-avbildet lagt til, og ingenting annet. 2.11.0 kom bare for amd64 for å nå produksjon først og stå som stabil, og det gjorde den: et anlegg kjørte den med 13 727 noder og uten omstarter. Dette er den lille oppdateringen som bygger begge. Koden, chartet, innstillingene og flytene dine endres ikke.

## Hva som er endret

- Avbildet bygges for linux/amd64 og linux/arm64. Taggene `2.11.1`, `2.11` og `2` har begge.
- README og installasjonssidene nevner 2.11.1 og sier amd64 og arm64. Installasjonslinjen i README i 2.11.0 pekte fortsatt på 2.10.2-avbildet; nå nevner den 2.11.1.

## Nye innstillinger

Ingen.

## Oppgradering

En enkel `helm upgrade` til 2.11.1-imaget og -charten, eller den nye taggen i Quadlet-enheten din. Hvis du er på arm64 og ble på 2.10.2 mens 2.11.0 bare var amd64, er dette ditt steg til case-strukturredigereren, utvalg til underdiagram, ryddig oppsett, navngitte forbindelser, zoom til 400 prosent, nodesymboler, panelobjektsetteren og diagramskriveporten: les notatene for 2.11.0 for hva de er og hva som ikke er bevist. Ingenting skjer ved første oppstart, og ingenting må migreres.

Image: `ghcr.io/hotloop-io/hotloop-flow:2.11.1`, linux/amd64 og linux/arm64. Chart: `https://hotloop.io/hotloop-flow/`. README-en på denne taggen har resten, med bilder: https://github.com/HotLoop-io/hotloop-flow/blob/v2.11.1/README.md
