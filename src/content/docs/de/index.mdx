## Die Familie

HotLoop sind acht Produkte für die Fertigung: vier, die mit einem Standort wachsen (IoT, Edge, Gateway und Edge Relay), dazu Flow für die Verdrahtung, Cascade für Workflows, HotLoop for CODESYS für den eigenen Bildschirm der SPS und Transmitter, um die Werte einer SPS ins Netz zu bringen. Sie erscheinen in fünf Release-Linien, jede mit ihrer eigenen Version. Jeder Abschnitt der Seitenleiste zeigt nur, was das Produkt ausliefert, und ein größeres Produkt verweist auf die Seiten, die es von einem kleineren übernimmt.

## So lesen Sie diese Dokumentation

**„Verifiziert“ heißt, es lief gegen das echte System:** einen echten OPC-UA-Server, einen echten Broker, Ignition selbst und echte Anlagen auf physischer Hardware. Das ist die Latte für jede Aussage auf diesen Seiten. Wenn eine Seite sagt, dass ein Protokoll oder eine Funktion funktioniert, ist es gelaufen.

**Das neueste Release ist das, was Sie installiert haben.** Eine Seite, die etwas Neueres beschreibt als das veröffentlichte Release, trägt ein Abzeichen **Nächstes Release** und einen Hinweiskasten oben, damit Sie immer wissen, was in Ihrer Installation steckt und was noch kommt.
