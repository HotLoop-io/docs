HotLoop Transmitter ist eine CODESYS-Bibliothek, die SPS-Werte als OPC UA PubSub über UDP veröffentlicht. Sie ist keine App im App Store, aber die EmberNet-Dokumentation erwähnt sie, und dort begegnet ihr ein EmberNet-Anwender.

Die EmberNet-Seiten, die sie erwähnen:

- [HotLoop Gateway auf EmberNet](https://docs.embernet.ai/docs/app-store/hotloop)
- [HotLoop for CODESYS auf EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-codesys)

[HotLoop im Unternehmen nutzen](/de/business/) behandelt die Lizenzierung und wie Sie uns erreichen.

Zurück zur [Übersicht von HotLoop Transmitter](/de/transmitter/overview/) oder zur [HotLoop-Transmitter-Seite auf hotloop.io](https://hotloop.io/transmitter/).
