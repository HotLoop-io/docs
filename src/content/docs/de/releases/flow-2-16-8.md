HotLoop Flow 2.16.8 sorgt dafür, dass sich ein aus Node-RED mitgebrachter Flow so verhält wie dort, und stellt sicher, dass ein merkwürdiger Wert nie das Flow Ihrer Anlage zu Fall bringen kann. An Ihren Flows, Einstellungen oder Ihrem Chart ändert sich nichts.

## Was sich geändert hat

- **Ein Wert, der sich selbst enthält, hält Flow nicht mehr an.** Node-RED lässt einen Change-Node eine Liste in sich selbst schreiben, etwa `msg.payload[0]` auf `msg.payload` setzen, und macht weiter. Flow folgte dieser Schleife, bis der Stack aufgebraucht war und der ganze Prozess beendet wurde. Jetzt wird die Schleife dort gekappt, wo sie auf sich selbst zurückläuft, dieser eine Node meldet „der Wert verweist auf sich selbst“ wie jeder andere Node-Fehler, und jeder andere Flow läuft weiter. Derselbe Schutz gilt für einen Function-Node, der einen solchen Wert zurückgibt, sendet oder setzt. Wir haben es mit den Flows einer echten Anlage nachgestellt, 13.737 Nodes, die einem Modbus-Simulator antworteten: Der alte Build starb binnen einer Minute, dieser lief weiter.
- **Function-Nodes sprechen modernes JavaScript.** `await`, ein vom Body zurückgegebenes Promise, ein Setup-Promise, das die erste Nachricht zurückhält, bis es aufgelöst ist, und `node.linkcall` funktionieren alle, sodass eine für Node-RED 4 geschriebene Funktion so läuft, wie sie geschrieben ist. Ein Fehler, den kein Catch-Node übernimmt, wird als unbehandelt markiert, wie Node-RED ihn markiert.
- **Node-REDs eigene Beispiel-Flows liefern Node-REDs Ausgabe.** Alle 62 aufgezeichneten Beispiele stimmen jetzt mit dem überein, was das echte Node-RED erzeugt hat. Diese Version korrigiert die Teilezahlen, die ein Switch schreibt, den Typ, den ein csv-Node seinen Zeilen aufstempelt, `msg.columns` und `msg.reset` bei csv sowie Reset und Flush für Nachrichten, die ein Delay festhält.
- **FlowLab liest das Blockdiagramm eines LabVIEW-VI.** Nodes, Verbindungen, Konstanten, Bedienelemente, Anzeigen und Strukturkörper kommen herüber, und alles, wofür FlowLab kein Äquivalent hat, bleibt als benannter Node sichtbar, sodass Sie sehen, wo das Diagramm endet.
- **Ein größeres, weiterhin eigenständiges Binary.** Flow bleibt ein statisches Binary mit dem Editor darin. Es darf jetzt auf 58 MiB wachsen, um all das Obige aufzunehmen.

## Neue Einstellungen

Keine.

## Upgrade

Ein schlichtes `helm upgrade` auf das Image und Chart von 2.16.8 oder das neue Tag in Ihrer Quadlet-Unit. Beim ersten Start passiert nichts, und es gibt nichts zu migrieren. Eine Flow-Datei wird Byte für Byte wie bisher geladen und gespeichert. Diese Version baut das amd64-Image. Die Tags `2.16` und `2` behalten das arm64-Image, das sie schon von 2.16.1 halten, und eine kleine Folgeversion ohne sonst etwas bringt arm64 zurück. Wenn Sie auf arm64 sind, bleiben Sie bis dahin auf 2.16.1.
