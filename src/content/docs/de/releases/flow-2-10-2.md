Nutzen Sie 2.10.2. Code, Chart, Einstellungen und Ihre Flows ändern sich nicht.

## Was sich geändert hat

- Das Image wird für linux/amd64 und linux/arm64 gebaut. Die Tags `2.10.2`, `2.10` und `2` enthalten beide.
- README und Installationsseiten nennen 2.10.2.

## Neue Einstellungen

Keine.

## Upgrade

Ein einfaches `helm upgrade` auf das Image und Chart 2.10.2, oder das neue Tag in Ihrer Quadlet-Unit. Von 2.10.0 aus ändert sich auf amd64 nichts. Wenn Sie auf arm64 sind und noch auf 2.9.1, ist das Ihr Schritt zu allem, was in den Hinweisen zu 2.10.0 steht: die Instrumente von FlowLab, die Case-Struktur, Wellenformen, gemeinsame Datensatztypen, Unterdiagramme und Log-Rotation, die MCP-Werkzeuge, die Flows auflisten, lesen, bereitstellen und zurücksetzen, der auf das Speicherlimit des Containers begrenzte Heap und die Korrektur, die verhindert, dass eine dauerhafte MQTT-Ausgabe nach einer Wiederverbindung eine Nachricht zweimal sendet. Beim ersten Start passiert nichts, und es muss nichts migriert werden. Wenn etwas 2.10.1 festgelegt hatte, stellen Sie es auf 2.10.2 um: Dieses Image gibt es nicht.

Image: `ghcr.io/hotloop-io/hotloop-flow:2.10.2`, linux/amd64 und linux/arm64. Chart: `https://hotloop.io/hotloop-flow/`. Das README zu diesem Tag hat den Rest, mit Bildern: https://github.com/HotLoop-io/hotloop-flow/blob/v2.10.2/README.md
