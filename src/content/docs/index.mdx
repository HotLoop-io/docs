## What these docs will and will not tell you

They will tell you what each product does, how far each piece has been proven, and what is not done yet. Both products keep a table of what has and has not been verified against real equipment, and these docs repeat it instead of rounding up.

They do not yet cover installation. The images, charts, and command names are changing as both products move into this organization, and a command that is wrong within a week is worse than no command. Installation pages will land when the names are final.

For the products' current status, see the [release notes](https://hotloop.io/releases/) and the [integrations table](https://hotloop.io/integrations/).
