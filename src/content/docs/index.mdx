## The family

HotLoop is six products for the plant floor: four that grow with a site (IoT, Edge, Gateway, Edge Relay), plus Flow for wiring and Cascade for workflows. They ship on three release lines, so each carries its own version. Each section in the sidebar shows only what that product ships, and a bigger product links back to the pages it carries from a smaller one.

## How to read these docs

**"Verified" means it ran against the real thing:** a real OPC UA server, a real broker, Ignition itself. Anything tested against a simulator or a stand-in says exactly that, and a page that describes something nobody has run on a bench says so before it tells you how to use it.

**Pages follow `main`, and the latest release is what you have installed.** A page that describes something newer than the release carries a **Next release** badge and a box at the top. A page that has moved since the release says so. The page header and the [release notes](/releases/) tell you which side of the line you're on, so you find out here, not after an upgrade.

**The docs are synced from the products' own repos,** at their current `main`, and rebuilt every release. Two of those repos are private, so the sync runs from a clone and its result is committed here.
