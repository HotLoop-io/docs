## The family

HotLoop is eight products for the plant floor: four that grow with a site (IoT, Edge, Gateway, and Edge Relay), plus Flow for wiring, Cascade for workflows, HotLoop for CODESYS for the PLC's own screen, and Transmitter for putting a PLC's values on the wire. They ship on five release lines, so each carries its own version. Each section in the sidebar shows only what that product ships, and a bigger product links back to the pages it carries from a smaller one.

## How to read these docs

**"Verified" means it ran against the real thing:** a real OPC UA server, a real broker, Ignition itself, and real equipment on bare metal. That is the bar for every claim in these pages, so when a page says a protocol or a feature works, it ran.

**The latest release is what you have installed.** A page that describes something newer than the release carries a **Next release** badge and a box at the top, so you always know what is in your install and what is coming.
