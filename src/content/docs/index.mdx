## What these docs will and will not tell you

They will tell you what each product does, how far each piece has been proven, and what is not done yet. The Gateway and Flow each keep a table of what has and has not been verified against real equipment, and these docs repeat it instead of rounding up.

They cover installing what you can actually install: [the Gateway](/gateway/install/), [the Edge Relay](/edge-relay/install/) and [Flow](/flow/install/). IoT and Edge get install pages the day they ship, not before, because a command for an image that doesn't exist is worse than no command.

For the products' current status, see the [release notes](https://hotloop.io/releases/) and the [integrations table](https://hotloop.io/integrations/).
