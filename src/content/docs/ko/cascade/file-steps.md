파일 단계(읽기, 쓰기, 나열, 이동, 삭제, CSV 또는 Excel 파일 만들기, Excel 또는 PDF의 텍스트 읽기, 파일이 나타날 때의 트리거)는 하나의 디렉터리 `HOTLOOP_CASCADE_FILES_DIR`에서만 동작하며 그 바깥의 어떤 것에도 접근할 수 없습니다. 설정하지 않으면 꺼져 있습니다.
