끝난 것과 남은 것을 처리하는 순서대로 적은 목록입니다. 코드나 테스트 계획에 없는 것은 약속하지 않으며, 어디까지 실행해 봤는지는 [현황](/ko/codesys/where-it-stands/)에 있습니다.

## 구축됨

- [x] 노드의 런타임을 위한 기본값을 갖춘 HotLoop Edge 주변의 차트: SQLite, 레플리카 하나, 컨트롤 플레인을 잃어도 두 파드를 유지하는 톨러레이션.
- [x] 프로필을 적용하고 올바르게 유지하는 프로비저너. 사람이 바꾼 것을 보호하는 리비전이 있습니다.
- [x] HotLoop이 다루는 어떤 프로토콜의 장치 목록이든 담는 프로필. PLC 없이도 리스너가 설정된 상태로 돌아옵니다.
- [x] 컨테이너 안의 CODESYS Control for Linux SL 4.22.0.0 런타임을 상대로, 수작업 없이 만든 장치, 태그, 알람, 화면.
- [x] 런타임 재시작 후 사람 손 없이 약 88초 만에 복구.
- [x] EmberCORE 대시보드에서의 서명된 로그인과 거부 처리.

## 출시됨

- [x] HotLoop 4.22.0, 차트가 감싸는 릴리스.
- [x] `https://hotloop.io/hotloop-codesys/`에 게시된 차트, 최신은 0.3.8.
- [x] 로그인 없이 받을 수 있도록 공개된 프로비저너 이미지, 0.3.3.
- [x] 0.3.3과 차트 0.3.8부터 amd64와 arm64를 지원하는 멀티 아키텍처 프로비저너 이미지.
- [x] HotLoop 4.22.0과 차트 0.3.7에서 하나의 UDP 포트에 OPC UA PubSub 리스너 둘.
- [x] 0.3.0부터 0.3.8까지 모든 차트의 [릴리스 노트](/ko/releases/codesys-0-3-8/).

## 베어메탈에서 검증됨

- [x] 베어메탈에서 실행(2026-11-17): 직원이 하는 방식 그대로 실제 App Store 페이지에서 설치, k3s v1.35.7, 파드는 유지한 채 컨트롤 플레인과의 연결을 실제로 잃는 노드, 런타임이 계속 동작하는 상태에서 CODESYS IDE로 다운로드, 한 노드에서 HotLoop 파드 옆에 호스트 자체 네트워크로 동작하는 런타임, 사용자 관리를 켠 런타임과 인증서로 보호한 OPC UA 엔드포인트.
