이번 릴리스에는 4.23.0 노트에 나열된 모든 것이 들어 있습니다. 날씨와 에너지, 열세 개 언어가 더해진 웹 UI, 파일로 설치 사이를 옮겨 다니는 화면, 그리고 UniFi 콘솔에 대한 첫 명령입니다. amd64 전용으로 빌드되었고 멀티 아키텍처 빌드는 다음 버전으로 이어집니다.

## 바뀐 내용

- **기상 관측소는 하나의 엔티티입니다.** 지붕 관측소가 이미 게시하는 tag(온도, 습도, 기압, 바람, 비, 일사)로 만들며, 이슬점, 열지수, 체감 한파는 박스에서 계산합니다. 관측소에 주어지지 않은 센서에는 행이 없고, 응답을 멈춘 센서는 0이 아니라 Unavailable로 읽힙니다. 클라우드 서비스는 호출하지 않습니다. [Weather](/ko/iot/weather/)를 보세요.
- **에너지 미터.** 미터는 사용량으로 읽히는 tag입니다(kWh, 가스, 물, 공기 같은 누적 카운터 또는 전력). 사용한 양은 15분 버킷으로 보관되므로 재시작해도 잃는 것이 없고, 교대, 하루, 한 달은 합계입니다. 요금제는 버킷이 만들어질 때 각 버킷에 비용을 부여하므로 나중에 바뀐 가격이 지난달 비용을 바꾸지 않으며, 생산한 단위당 비용은 생산 미터로 계산합니다. Energy 화면, API, MCP 도구가 있습니다. [Energy](/ko/iot/energy/)를 보세요.
- **웹 UI가 영어 옆에 열세 개 언어로 더 제공됩니다.** 스페인어, 프랑스어, 이탈리아어, 독일어, 노르웨이어, 불가리아어, 그리스어, 한국어, 일본어, 베트남어, 힌디어, 중국어 간체, 그리고 오른쪽에서 왼쪽으로 배치되는 아랍어입니다. 상단 막대나 로그인 카드에서 고르세요. [Languages](/ko/iot/languages/)를 보세요.
- **대시보드를 파일로 내보내고 다른 설치로 가져올 수 있습니다.** 고객의 화면은 고객의 것이며 제품의 일부가 아닙니다. 파일에는 그 화면이 언급하는 모든 tag, 장치, 스크립트, 레시피가 나열되고, 가져오기는 무엇이든 저장하기 전에 이름이 다른 경우의 매핑과 함께 모든 문제를 한꺼번에 보고합니다. Export와 Import는 Dashboards 화면의 버튼이며, `screen_export`와 `screen_import`는 MCP 도구입니다. [Screen files](/ko/iot/screen-file/)를 보세요.
- **쓰기와 짝을 이루는 MCP 읽기**, 편집기의 드라이 런, CODESYS 알람 가져오기입니다.
- **UniFi 콘솔에 대한 첫 명령.** 다섯 종류의 포인트를 명령할 수 있으며, 각각은 사람이 해당 tag를 활성화하기 전까지 읽기 전용이고 다른 tag와 같이 쓰기 게이트를 지납니다. 장치의 위치 확인 LED, 장치 재시작, 스위치 포트의 PoE 전원 사이클, 무선 네트워크 켜기/끄기, 감시 중인 클라이언트의 차단과 허용, 포트의 PoE 모드입니다. 전원 사이클에는 데이터베이스에 보관되는 15분 쿨다운이 적용되므로 재시작해도 잊지 않으며, 네트워크를 나르는 포트(업링크, 스위치, 게이트웨이, 5G 백업, 콘솔이 나열하지 않는 피어)는 절대 사이클하지 않습니다. HotLoop이 로그인하는 콘솔 계정은 이를 위해 로컬 Administrator여야 하며, View Only 계정은 콘솔이 거부하고 HotLoop이 그렇게 알려 줍니다. 기본 제공 blueprint는 응답 없는 장치의 포트를 한 번 사이클한 다음 알람을 올립니다. [UniFi Network](/ko/iot/unifi/)를 보세요.
- **OPC UA 서버가 HistoryRead에 응답합니다.** Gateway가 보관하는 이력에서 원시 값과 처리된 값을 제공합니다.
- **OPC UA PubSub delta 프레임이 옵션으로 추가됩니다.** `HOTLOOP_UADP_PUBLISH_DELTA_FRAMES=true`는 key 프레임 사이에 바뀐 필드만 보냅니다. 기본값은 꺼짐입니다.
- **패널 페이지의 그림 카드가 카드에 맞춰지며** 더 이상 행 높이를 정하지 않습니다.
- **Quadlet 설치의 데이터베이스 업그레이드 유닛은 볼륨에 업그레이드할 것이 없으면 스스로 건너뜁니다.** Podman 5.7은 실행할 것이 없는 컨테이너를 시작하지 않기 때문이며, 포함된 데이터베이스의 이름은 StatefulSet이 가질 수 있는 52자에 맞춰졌습니다.
- **차트는 제거할 때 자격 증명 Secret을 남겨 둡니다.** 데이터베이스 볼륨과 같습니다. 같은 이름으로 재설치하면 남은 데이터베이스가 거부하는 새 비밀번호가 생성되곤 했습니다. 깨끗하게 시작하려면 볼륨과 함께 Secret을 손으로 삭제하세요.
- **Kafka 출력은** 방금 만든 topic을 브로커에서 연결이 허용하는 만큼 기다리며, Edge Relay의 문서화된 중단 큐 수치는 측정값입니다(초당 2,000개 읽기에서 약 2분).
- 테스트 스위트가 찾은 수정: OPC UA 테스트 사용자는 bcrypt의 가장 낮은 비용으로 해시되므로 스위트의 로그인이 느린 러너에서 테스트 클라이언트가 기다리는 시간을 넘지 않습니다(서버와 로그인은 그대로입니다). 라이브 피드는 마지막 페이지가 떠나는 순간 보낸 것을 잊습니다. OPC UA 서버는 리스너가 포트를 잡고 있을 때 그렇게 알립니다. 그리고 여러 테스트가 자체 속도로 일어나는 일을 더 이상 sleep으로 기다리지 않습니다.

## 마이그레이션

두 개이며 각각 추가만 합니다. `0028_unifi_port_cycles`(각 스위치 포트가 마지막으로 전원 사이클된 시각)와 `0029_energy`(미터와 버킷을 위한 테이블 세 개)입니다. 둘 다 백업에 포함됩니다. 4.22.1에서 만든 백업은 여기서 복원되며, 여기서 만든 백업은 이전 릴리스에 복원되지 않습니다.

## API 변경 사항

새 라우트: `GET /api/energy/meters`, `POST /api/energy/meters`, `GET`, `PUT`, `DELETE /api/energy/meters/{id}`, `GET /api/energy/summary`와 `/api/energy/summary/{period}`, `GET /api/energy/series`와 `/api/energy/series/{meter}/{period}/{step}`, `GET /api/dashboards/{id}/export`, `POST /api/dashboards/import`, `GET /api/entities/composites`. 새 권한 두 개: 모든 역할이 가진 `energy.read`와 관리자가 가진 `energy.write`입니다. 각각에 대한 새 MCP 도구가 있습니다. 기상 관측소는 새 엔티티 도메인 `weather`입니다. [HTTP API](/ko/iot/api/)를 보세요.

## 4.22.1에서 업그레이드

평범한 `helm upgrade`입니다. 마이그레이션은 첫 시작에 실행되어 테이블을 추가하며, 새 secret은 없습니다. 꺼져 있던 것은 켜지지 않습니다.

## 검증되지 않은 것

- 나머지 명령은 실제 콘솔을 상대로 실행해 보지 않았습니다.
- 날씨와 에너지는 녹화 데이터, Modbus 장비, Emberburn의 시뮬레이션 카운터를 상대로 실행했으며, 실제 지붕 관측소나 플랜트의 미터는 아닙니다.
- 열세 개의 새 언어 카탈로그는 공유 용어집으로 작성했으며 원어민이 검토하지 않았습니다.
