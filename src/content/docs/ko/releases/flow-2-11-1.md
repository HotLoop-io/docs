HotLoop Flow 2.11.1은 2.11.0에 arm64 이미지를 더했을 뿐 그 밖에는 없습니다. 2.11.0은 먼저 운영 환경에 올라가 안정 버전으로 표시되도록 amd64만 내놓았고, 실제로 그렇게 되었습니다. 한 공장이 노드 13,727개로 재시작 없이 실행했습니다. 이번은 둘 다 빌드하는 작은 후속 버전입니다. 코드, 차트, 설정, 사용 중인 플로는 바뀌지 않습니다.

## 바뀐 내용

- 이미지는 linux/amd64와 linux/arm64용으로 빌드됩니다. `2.11.1`, `2.11`, `2` 태그는 둘 다 담습니다.
- README와 설치 페이지는 2.11.1을 가리키고 amd64와 arm64를 함께 안내합니다. 2.11.0의 README 설치 줄은 아직 2.10.2 이미지를 가리켰는데, 이제 2.11.1을 가리킵니다.

## 새 설정

없습니다.

## 업그레이드

2.11.1 이미지와 차트로 `helm upgrade`만 하거나 Quadlet 유닛의 새 태그를 쓰면 됩니다. arm64를 쓰면서 2.11.0이 amd64 전용인 동안 2.10.2에 머물렀다면, 지금이 case 구조 에디터, 선택 영역을 서브 다이어그램으로 만들기, 깔끔한 정렬, 이름 있는 와이어, 400퍼센트까지 확대, 노드 기호, 패널 오브젝트 설정기, 다이어그램 쓰기 게이트로 옮겨 갈 때입니다. 2.11.0 노트에서 이들이 무엇이고 무엇이 검증되지 않았는지 읽어 보세요. 처음 시작할 때 일어나는 일은 없고 마이그레이션도 필요 없습니다.

이미지: `ghcr.io/hotloop-io/hotloop-flow:2.11.1`, linux/amd64 및 linux/arm64. Chart: `https://hotloop.io/hotloop-flow/`. 이 태그의 README에 나머지가 그림과 함께 있습니다: https://github.com/HotLoop-io/hotloop-flow/blob/v2.11.1/README.md
