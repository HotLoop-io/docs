## 개요

1.0.1은 데이터베이스를 읽을 수 없을 때 로그인이 처리하는 방식의 실수 하나를 고칩니다. 그 밖에는 1.0.0에서 바뀐 것이 없습니다.

## 수정 내용

데이터베이스가 잠깐 끊기면 Cascade는 "조회하지 못했다"를 "유효하지 않다"로 읽고 401로 응답했습니다. 세션 확인, API 키, SCIM 토큰, 키의 사용자가 모두 그랬고, 세션 확인은 쿠키까지 지워서 짧은 장애에도 모두가 로그아웃되었습니다. 이제 존재하지 않거나 비활성화된 사용자의 세션만 401입니다. 읽을 수 없는 저장소는 Retry-After와 함께 503으로 응답하고 쿠키는 그대로 남습니다.

두 번째 인증 요소에도 같은 문제가 있었습니다. 장애 중에는 올바른 인증 앱 코드, 복구 코드, 패스키가 잘못된 코드로 응답되어 본인 계정에서 잠길 수 있었습니다. 이제 이 단계들은 저장소나 서버 오류에는 503으로 응답하고, 401은 잘못된 코드, 실패한 패스키, 만료된 요청 같은 실제 거부에만 씁니다. 패스키 로그인도 사용자 조회 실패를 "이 패스키를 가진 계정이 없다"로 읽지 않습니다.

## 업그레이드와 되돌리기

마이그레이션은 없습니다. 1.0.1로 `helm upgrade`하거나 `:stable`이 Quadlet 유닛을 옮기게 두세요. 데이터베이스에서 바뀌는 것이 없으므로 1.0.0으로 되돌려도 안전합니다. 업데이트 전에 백업하는 습관은 여전히 좋습니다.
