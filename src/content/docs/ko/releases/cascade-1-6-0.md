## 개요

1.6.0은 Cascade가 워크플로가 돌아가기만 하는 곳을 넘어, 사람과 모델과 다른 서버가 함께하는 곳이 되는 버전입니다. 실행이 멈추고 사람에게 휴대폰으로 물어볼 수 있습니다. 실행이 여러분의 모델에게 물어볼 수 있습니다. 워크플로를 Git에 둘 수 있고, 운영 인스턴스는 손으로 편집되는 것을 거부할 수 있습니다. 그리고 어떤 웹 API든 파일 하나로 스텝이 됩니다. 엔진, 파일 형식, 나머지는 모두 1.5.1과 같습니다.

## 휴대폰으로 사람에게 묻기

새 승인 요청 스텝은 실행을 멈추고 기다립니다. `execution.approvalUrl`을 푸시 알림에 넣으면 알림을 받은 사람이 탭해서 여러분이 쓴 내용을 읽고, 만들어 둔 작은 양식이 있으면 채운 뒤 승인 또는 거부를 누릅니다. 페이지는 단순하고 빠르며, 요청하지 않는 한 로그인이 필요 없고, 열네 가지 언어 모두에서 브라우저 언어로 표시됩니다. 실행은 승인됨 또는 거부됨 포트로 이어지며, 누가 언제 무엇을 답했는지가 함께 담깁니다. 모든 답변은 기록이 됩니다. 실행 화면의 편집기, `GET /api/v1/approvals` API, `list_approvals` MCP 서버, 감사 로그에서 볼 수 있습니다. 스텝에 로그인한 계정을 요구하게 하면 여러분이 나열한 계정의 답변만 받습니다. 링크는 한 번만 작동합니다. 기다리는 데는 비용이 들지 않으므로 답변이 일주일 뒤에 와도 어떤 재시작이든 견딥니다.

## 모델에게 묻기

새 스텝 두 가지, AI: 모델에게 묻기와 AI: 에이전트 실행입니다. 모델은 여러분의 것입니다. 자격 증명이 직접 운영하는 서버(Ollama, vLLM, llama.cpp)나 키를 가진 호스팅 서비스를 가리키며, OpenAI 프로토콜이나 Anthropic 프로토콜을 씁니다. 자격 증명이 가리키지 않은 곳으로는 아무것도 나가지 않고, 호스팅 서비스는 따로 없으며, 모든 호출은 다른 호출처럼 송신 정책을 거칩니다. 모델에게 묻기는 답을 항목에 텍스트로, 또는 여러분이 준 스키마에 맞는 JSON 객체로 담습니다. 에이전트 실행은 모델에게 목표와 도구 목록을 주는데, 각 도구는 여러분의 다른 워크플로입니다. 모델이 하나를 요청하면 Cascade가 실행하고 결과를 돌려주며, 모델이 답하거나 턴이 다할 때까지 반복합니다. 턴 사이에 실행은 데이터베이스에서 기다리므로 느린 도구가 워커를 붙잡지 않습니다.

## Git의 워크플로

프로젝트를 저장소, 브랜치, 폴더에 연결하고 푸시하거나 풀합니다. 푸시는 워크플로마다 파일 하나를 이름과 ID와 함께 쓰고, 푸시한 사람의 이름으로 그가 쓴 메시지를 달아 커밋합니다. 풀은 프로젝트를 저장소에 맞춥니다. 새 파일은 워크플로가 되고(켜기 전까지 꺼진 상태), 바뀐 파일은 새 버전이 되며, ID가 유지되어 워크플로는 모든 인스턴스에서 같습니다. 양쪽에서 바뀐 변경은 보고만 하고 누가 이길지 정하기 전까지 건드리지 않습니다. 삭제는 요청할 때만 일어납니다. 프로젝트마다 카드가 하나, API 경로가 여섯, MCP 도구가 여섯 있습니다. 금고에 보관된 사용자 이름과 토큰 또는 비밀번호로 송신 정책을 거쳐 HTTPS로 통신합니다.

## 보호된 인스턴스

인스턴스에 이름(개발, 스테이징, 운영)을 붙이면 모든 화면 위쪽 배지에 표시됩니다. 설정에서, 또는 `HOTLOOP_CASCADE_PROTECTED`(어떤 설정으로도 되돌릴 수 없는 차트의 `protected` 값)로 보호하면 편집기, API, MCP 어디에서도 워크플로를 손으로 만들거나 편집, 복원, 삭제할 수 없습니다. 워크플로는 Git에서 풀해서 들어옵니다. 자격 증명, 변수, 실행, 워크플로 켜기와 끄기는 환경마다 다르므로 열려 있습니다. 보호된 인스턴스는 풀만 하고 푸시는 하지 않습니다.

## 파일로 만드는 커넥터

커넥터는 API가 어디에 있고, 어떻게 로그인하며, 각 호출이 무엇을 받고 돌려주는지를 적은 파일입니다. `HOTLOOP_CASCADE_CONNECTORS_DIR`(데이터 디렉터리의 `connectors` 폴더)에 넣으면 모든 작업이 스텝이 되고, 양식과 고유한 자격 증명 유형, 페이지 나누기와 재시도가 기본 제공 커넥터와 같은 방식으로 정리됩니다. 형식은 공개되어 있고 버전이 있으며 JSON Schema(`hotloop-cascade connector schema`)가 있습니다. 작성 도구는 바이너리에 들어 있습니다. `connector init`, `validate`, `call`(실제 API로 작업 시험), 공유를 위한 `index`와 `install`이며, 인덱스는 해시가 붙은 정적 파일들입니다. Cascade는 여러분이 지정하지 않은 인덱스는 내려받지 않습니다. MCP 서버의 도구는 이제 91개입니다.

## 되돌리기

이 릴리스는 테이블 세 개(승인과 Git용 두 개)를 추가하며 마이그레이션은 앞으로만 갑니다. 따라서 1.5.1로 돌아가려면 이전 이미지만이 아니라 업그레이드 전에 만든 백업이 필요합니다. 기존 항목의 형태는 하나도 바뀌지 않습니다.
