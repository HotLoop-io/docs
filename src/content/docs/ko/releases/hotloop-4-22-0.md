패널로 연 화면(`/?screen=<name>`)이 이제 어떤 크기에서도 디스플레이를 가장자리까지 채우고, Alarms 화면이 CODESYS 알람 파일을 가져올 수 있으며, 몇 가지 수정이 있습니다. amd64 전용으로 빌드되었고 멀티 아키텍처 빌드는 다음 버전으로 이어집니다.

## 바뀐 내용

- **패널 페이지가 화면을 가득 채웁니다.** 1920x1080, 1366x768, 3840x2160에서 빈 공간 없이 디스플레이를 덮습니다. 플랜트 이름이 있는 헤더, 온라인 장치 수가 있는 Live 상태, 날짜가 있는 24시간 시계가 있습니다. 숫자와 게이지는 화면과 함께 커지며, 추이의 축과 범례도 그렇습니다. 바뀌는 것은 패널 페이지뿐이며, 대시보드는 그대로이고 고객의 카드, 크기, 이름은 고객의 것입니다.
- **Alarms 화면이 CODESYS Export Alarms 파일을 가져옵니다.** 관리자 전용입니다. 장치를 고르고, 애플리케이션 이름을 정하고, 파일을 고르고, 넘어오는 것과 넘어오지 않는 것의 미리 보기를 읽은 다음 가져옵니다. API 라우트는 이미 있었습니다.
- **같은 주소와 포트의 OPC UA PubSub 장치는 소켓 하나를 공유합니다.** 두 번째 장치는 바인드할 수 없었고, 재사용 옵션은 발행자의 데이터그램을 둘 사이에 나눠 버렸습니다.
- **느린 응답이 더 이상 쌓이지 않습니다.** 새로 고침보다 느린 카메라 카드가 이제 그림을 보여 주고, 카드와 UniFi 화면은 마지막 응답 뒤에만 다시 묻고, 한 번 실패한 디스커버리 배치는 재시도되며, 호스트 이름을 쓰는 SNMP 장치는 응답에 대한 자신의 대기 시간을 유지합니다.
- **코어 제품은 HotLoop Free Use License 1.0을 따릅니다.** 이전 버전은 게시될 때의 조건을 그대로 유지합니다. NOTICE를 보세요.
- **차트 페이지의 App Store 아이콘**은 HotLoop 브랜드 마크입니다.

## API 변경 사항

없습니다.

## 4.21.1에서 업그레이드

평범한 `helm upgrade`입니다. 마이그레이션도, 새 secret도, 되돌릴 수 없는 것도 없습니다.

## 테스트

패널 페이지는 위의 세 크기에서 Emberburn이 Gateway에 데이터를 공급하는 상태로 테스트에서 확인했습니다.
