---
title: "بناء Flow من المصدر"
description: "ابنِ الملف الثنائي لـ Flow من المصدر: ملف ثنائي ثابت يضم المحرر في داخله ولا توجد مكتبة C تحته."
---

HotLoop Flow ملف ثنائي ثابت يضم المحرر في داخله، لذلك يسحب معظم الناس الصورة المنشورة ولا يبنون شيئًا أبدًا. وإن أردت بناءً خاصًا بك، فالشيفرة المصدرية عامة، ويحتاج البناء إلى Go وNode.

```bash
cd web && npm install && npm run build && cd ..
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o hotloop-flow ./cmd/hotloop-flow
```

الناتج ثابت ولا توجد مكتبة C تحته، لذا يعمل على صورة distroless لا يُثبَّت عليها أي شيء آخر. يُبنى كل إصدار من Flow من وسم إصدار ولا من شيء سواه، فتكون الصورة في مصنعك دائمًا صورة يمكنك تسميتها وتتبعها إلى إصدار.
