تأتي واجهة الويب في HotLoop IoT وEdge وGateway (وفي HotLoop for CODESYS الذي يشغّل واجهة Edge) بالإنجليزية و13 لغة أخرى: الإسبانية (es) والفرنسية (fr) والإيطالية (it) والألمانية (de) والنرويجية بوكمول (nb) والبلغارية (bg) واليونانية (el) والكورية (ko) واليابانية (ja) والفيتنامية (vi) والهندية (hi) والصينية المبسّطة (zh-Hans) والعربية (ar، مرتبة من اليمين إلى اليسار).

اختر لغة من مربع اللغة في الشريط العلوي أو من بطاقة تسجيل الدخول. يُحفظ الاختيار في هذا المتصفح. وإن لم يُختر شيء، تستخدم الصفحة أول لغة من لغات المتصفح تتوفر لدى HotLoop، والإنجليزية إن لم تتطابق أي لغة. تظهر اللغة في قائمة الاختيار فقط عندما يكتمل ملفها.

ما يتبع اللغة: كل كلمة في كل شاشة، وترتيب الأرقام وعلاماتها (فاصلة عشرية في الألمانية والفرنسية والإسبانية)، والتواريخ والأوقات (نظام 24 ساعة)، وصيغ الجمع (للعربية ست صيغ)، واتجاه الصفحة. تبقى أسماء المنتجات والبروتوكولات (HotLoop وModbus وOPC UA وMQTT وSparkplug وCODESYS وUniFi) كما هي مكتوبة. أما القيم القادمة من المصنع، مثل أسماء الوسوم وأسماء الأجهزة ورسائل الإنذار التي كتبها شخص ما ونص الخطأ الذي يعيده الخادم، فتُعرض كما هي.

## كيف يعمل

* تبحث [i18next](https://www.i18next.com/) 27 عن الرسالة وتملأ `{{name}}` وتختار صيغة الجمع. وهي تسأل `Intl.PluralRules` الخاص بالمتصفح نفسه، فقواعد الجمع هي قواعد Unicode CLDR. تستخدم الأرقام والتواريخ `Intl.NumberFormat` و`Intl.DateTimeFormat` عبر `web/src/lib/format.ts`.
* توجد الرسائل في `web/src/i18n/locales/<language>.json`، بشكل مسطح، بمفتاح واحد لكل رسالة. `en.json` هو المصدر. وكل ملف آخر فيه المفاتيح نفسها تمامًا.
* في قالب أو سكربت، اكتب `tl('area.key')` أو `tl('area.key', { name })`. الرسالة ذات العدد لها مفتاح لكل صيغة جمع (`key_one` و`key_other`، و`key_few` و`key_many` و`key_two` و`key_zero` حيث تكون في اللغة) وتُطلب بالمفتاح وحده مع `count`: `tl('overview.tags_count', { count: n })`.
* الإنجليزية جزء من الصفحة. أما اللغة الأخرى فملف منفصل، يُجلب عندما يختارها أحد.
* يحفظ `web/src/i18n/index.svelte.ts` اللغة؛ وتغييرها يعيد رسم كل شاشة. الكلمة المحفوظة في ثابت في أعلى ملف `.ts` تُقرأ مرة واحدة عند تحميل الملف ولا تُترجم: اكتبها على شكل getter (`get label() { return tl('x.y'); }`) أو احتفظ بالمفتاح واستدعِ `tl()` حيث تُرسم.
* تضبط الصفحة `<html lang dir>`. يستخدم CSS خصائص منطقية (`margin-inline-start` و`inset-inline-end` و`text-align: start`)، لذلك ينقلب التخطيط من تلقاء نفسه للعربية.

## إضافة كلمة أو تغييرها

1. أضف الرسالة إلى `en.json` واكتبها في الشيفرة باستخدام `tl()`.
2. أضفها إلى كل ملف لغة آخر، يكتبها شخص يقرأ تلك اللغة، وفق قاعدة المصطلحات المشتركة في codex (`work/notes/i18n/glossary/`). جمل قصيرة وواضحة. تبقى أسماء المنتجات والبروتوكولات بالإنجليزية.
3. شغّل `cd web && npm run check:i18n`. يفشل عندما ينقص ملف لغة مفتاح، أو يحمل `{{placeholder}}` مختلفًا عن الإنجليزية، أو تنقصه صيغة جمع تحتاجها لغته؛ وعندما لا يُستخدم مفتاح؛ وعندما تُكتب الإنجليزية في قالب أو في الشيفرة دون المرور عبر `tl()`. يعمل قبل كل `npm run build` وفي `npm run typecheck`، فتتوقف عنده الحزمة الكاملة من الاختبارات وبناء الإصدار. أما الإنجليزية المقصود بقاؤها (اسم، مثال شيفرة) فتوضع في `web/i18n/allow.json` مع السبب.

اضبط `HOTLOOP_TEST_BROWSER_GALLERY` و`HOTLOOP_TEST_BROWSER_ARTIFACTS` للاحتفاظ بلقطة شاشة لكل منها.

## ما لا يُترجم

* النص الذي يرسله الخادم: رسائل الخطأ من API، ورسائل الإشعارات والإنذارات، وCLI. تعرضها الواجهة كما تصل.
* الوثائق، وأسماء خادم OPC UA، ووسيط MQTT، وقيم Helm chart.
