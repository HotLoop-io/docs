このページは、公開されているものと、HotLoop for CODESYS をどこまで動かしたかをまとめたものです。

## 公開済みのもの

- **チャート。** `hotloop-codesys` 0.3.8 は `https://hotloop.io/hotloop-codesys/` のインデックスに 2026-11-19 に公開され、以前のバージョンもすべて並んでいます。HotLoop 4.22.0 を包んでいます。0.3.8 のインストール: 各チャートの変更点は[リリースノート](/ja/releases/codesys-0-3-5/)にあります。
- **プロビジョナーイメージ。** 0.3.3 の `ghcr.io/hotloop-io/hotloop-provision` は、amd64 と arm64 のどちらもログインなしで取得でき、チャートがこれを実行します。
- **App Store の掲載。** EmberCORE App Store にあり、EmberNet がテナントにインストールします。

## どこまで動かしたか

Store 形式の値を使った k3s ノード上のチャート、同じノード上でデモプログラムを動かす実際の CODESYS Control for Linux SL 4.22.0.0 ランタイム、そして HotLoop Edge イメージ。

- デバイス、そのタグ (書き込み可能なものなし)、アラーム、画面が、手作業なしで現れました。
- すべての値が正常に読め、動きました。
- ポッドを削除しても、ポッドは戻りました。
- ランタイムの再起動中、インストールは「the PLC's runtime is not answering」という理由で不良として読まれ、約 88 秒後に自力で復旧しました。
- ダッシュボードからの署名付きサインインで、人がオペレーターまたは管理者としてサインインでき、間違ったアプリ、間違ったテナント、期限切れ、間違った発行者、改ざんされたものは、それぞれ拒否されました。
- 公開されたチャートは、ライブのインデックスから Helm でレンダリングできます。

その下にあるコネクター、HotLoop core の CODESYS ドライバーは、CODESYS Control for Linux SL 4.22.0.0 ランタイムに対して読み取りと書き込みをライブで検証済みで、ベアメタルでも検証しています (2026-11-17)。書き込みはコネクターにありますが、この製品はそれを有効にしません。

これらすべてをベアメタルでも実行しました (2026-11-17)。

## プロファイルにまだできないこと

プロファイルが作る画面は 1 つです。`device` からデバイス 1 つ、または `devices` からあらゆるプロトコルの複数のデバイスを作ります。プロファイルから変数を書き込み可能にする方法は、意図的にありません。
