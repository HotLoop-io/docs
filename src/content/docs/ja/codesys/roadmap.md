終わったことと残っていることを、片づける順に並べた一覧です。コードやテスト計画にないことは約束せず、どこまで動かしたかは[現状](/ja/codesys/where-it-stands/)に書いてあります。

## 構築済み

- [x] ノード上のランタイム向けの既定値を持つ HotLoop Edge のチャート。SQLite、レプリカ 1 つ、コントロールプレーンを失っても両方のポッドを保つトレラレーション。
- [x] プロファイルを適用して正しい状態に保つプロビジョナー。人が変更したものを守るリビジョンつき。
- [x] HotLoop が扱うあらゆるプロトコルのデバイスのリストを持つプロファイル。PLC がなくてもリスナーが設定済みの状態で戻ってきます。
- [x] コンテナ内の CODESYS Control for Linux SL 4.22.0.0 ランタイムに対して、手作業なしで作られたデバイス、タグ、アラーム、画面。
- [x] ランタイム再起動からの人手なしの復旧。約 88 秒。
- [x] EmberCORE ダッシュボードからの署名付きサインインと、その拒否処理。

## リリース済み

- [x] HotLoop 4.22.0。チャートが包んでいるリリース。
- [x] `https://hotloop.io/hotloop-codesys/` で公開されたチャート。最新は 0.3.8。
- [x] ログインなしで取得できる公開のプロビジョナーイメージ、0.3.3。
- [x] 0.3.3 とチャート 0.3.8 から、amd64 と arm64 のマルチアーキテクチャのプロビジョナーイメージ。
- [x] HotLoop 4.22.0 とチャート 0.3.7 で、1 つの UDP ポートに OPC UA PubSub リスナー 2 つ。
- [x] 0.3.0 から 0.3.10 までのすべてのチャートの[リリースノート](/ja/releases/codesys-0-3-10/)。

## ベアメタルで実証済み

- [x] ベアメタルで実行 (2026-11-17)。スタッフが行うとおりに実際の App Store ページからインストール、k3s v1.35.7、ポッドを保ったままコントロールプレーンとのリンクを実際に失うノード、ランタイムが動いたままの CODESYS IDE からのダウンロード、1 つのノードで HotLoop ポッドの隣にホスト自身のネットワークで動くランタイム、ユーザー管理をオンにしたランタイムと証明書で保護した OPC UA エンドポイントを含みます。
