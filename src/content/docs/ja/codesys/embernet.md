HotLoop for CODESYS は、CODESYS ランタイムの隣で動く HotLoop です。EmberNet が App Store からパッケージ化して展開し、EmberNet のドキュメントがその側を扱っています。

EmberNet ドキュメントでの場所:

- [EmberNet 上の HotLoop for CODESYS](https://docs.embernet.ai/docs/app-store/hotloop-codesys)
- [App Store の概要](https://docs.embernet.ai/docs/app-store/overview)
- [EmberNet 上の HotLoop Gateway](https://docs.embernet.ai/docs/app-store/hotloop)
- [EmberNet 上の HotLoop Edge](https://docs.embernet.ai/docs/app-store/hotloop-edge)

Gateway のページでは、OPC UA PubSub を発行する CODESYS ライブラリ HotLoop Transmitter も扱っています。

[ビジネスでの HotLoop の利用](/ja/business/)で、ライセンスと連絡方法を説明しています。

[HotLoop for CODESYS の概要](/ja/codesys/overview/)に戻る、または [hotloop.io の HotLoop for CODESYS ページ](https://hotloop.io/codesys/)へ。
