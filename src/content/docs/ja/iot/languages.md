HotLoop IoT、Edge、Gateway(と、Edge の画面を動かす HotLoop for CODESYS)の Web 画面は、英語と 13 の言語で使えます。スペイン語(es)、フランス語(fr)、イタリア語(it)、ドイツ語(de)、ノルウェー語ブークモール(nb)、ブルガリア語(bg)、ギリシャ語(el)、韓国語(ko)、日本語(ja)、ベトナム語(vi)、ヒンディー語(hi)、簡体字中国語(zh-Hans)、アラビア語(ar、右から左のレイアウト)です。

上部バーの言語ボックス、またはサインインカードで 1 つ選びます。選択はこのブラウザーに保存されます。何も選ばなければ、ページはブラウザーの言語のうち HotLoop が持っている最初のものを使い、一致するものがなければ英語を使います。言語は、ファイルがそろったときだけ選択肢に出ます。

言語に合わせて変わるのは、すべての画面のすべての言葉、数値の並びと記号(ドイツ語、フランス語、スペイン語では小数点がカンマ)、日付と時刻(24 時間制)、複数形(アラビア語には 6 つあります)、ページの向きです。製品名とプロトコル名(HotLoop、Modbus、OPC UA、MQTT、Sparkplug、CODESYS、UniFi)は書かれたままです。タグ名、デバイス名、誰かが入力したアラームメッセージ、サーバーが返すエラーテキストなど、工場の値はそのまま表示されます。

## しくみ

* [i18next](https://www.i18next.com/) 27 がメッセージを探し、`{{name}}` を埋め、複数形を選びます。ブラウザー自身の `Intl.PluralRules` に尋ねるので、複数形の規則は Unicode CLDR のものです。数値と日付は `web/src/lib/format.ts` を通して `Intl.NumberFormat` と `Intl.DateTimeFormat` を使います。
* メッセージは `web/src/i18n/locales/<language>.json` にフラットな形で、1 メッセージにつき 1 つのキーで入っています。`en.json` が原本です。ほかのすべてのファイルは、まったく同じキーを持ちます。
* テンプレートやスクリプトでは `tl('area.key')` または `tl('area.key', { name })` と書きます。個数を伴うメッセージは複数形ごとに 1 つのキーを持ち(`key_one`、`key_other`、言語によっては `key_few`、`key_many`、`key_two`、`key_zero`)、キー名だけと `count` で呼び出します。`tl('overview.tags_count', { count: n })` がその例です。
* 英語はページの一部です。ほかの言語は別ファイルで、誰かが選んだときに取得されます。
* `web/src/i18n/index.svelte.ts` が言語を保持し、変更するとすべての画面が描き直されます。`.ts` ファイルの先頭の定数に入れた言葉は、ファイルの読み込み時に一度だけ読まれ、翻訳されません。ゲッター(`get label() { return tl('x.y'); }`)として書くか、キーを保持して描画する場所で `tl()` を呼んでください。
* ページは `<html lang dir>` を設定します。CSS は論理プロパティ(`margin-inline-start`、`inset-inline-end`、`text-align: start`)を使うので、アラビア語ではレイアウトがひとりでに反転します。

## 言葉の追加と変更

1. メッセージを `en.json` に追加し、コードでは `tl()` で書きます。
2. その言語を読める人が書いて、ほかのすべての言語ファイルに追加し、codex の共通用語集(`work/notes/i18n/glossary/`)に従います。短く平易な文にします。製品名とプロトコル名は英語のままです。
3. `cd web && npm run check:i18n` を実行します。言語ファイルにキーが足りない、英語と `{{placeholder}}` が違う、その言語に必要な複数形がない場合に失敗します。使われていないキーがある場合や、`tl()` を通さずに英語がテンプレートやコードに書かれている場合にも失敗します。すべての `npm run build` の前と `npm run typecheck` で実行されるので、フルスイートとリリースビルドはここで止まります。残すべき英語(名前、コード例)は、理由を添えて `web/i18n/allow.json` に入れます。

`HOTLOOP_TEST_BROWSER_GALLERY` と `HOTLOOP_TEST_BROWSER_ARTIFACTS` を設定すると、それぞれのスクリーンショットが保存されます。

## 翻訳されないもの

* サーバーが送るテキスト: API のエラーメッセージ、通知とアラームのメッセージ、CLI。画面は届いたとおりに表示します。
* ドキュメント、OPC UA サーバーの名前、MQTT ブローカー、Helm チャートの値。
