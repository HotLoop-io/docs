HotLoop Flow 2.15.0 は、FlowLab に、データベースが取りこぼしたものを保持するデータベースシンクと、終了した実行のリプレイを加え、エディタとノードのテキストを英語に加えて 13 言語で提供し、リプレイ用の MCP ツールを 1 つ加えます。amd64 が先で、arm64 は 2.15.1 で続きます。

## 新機能

- **FlowLab ダイアグラム用の Postgres out(#193)。** 新しいノード `dia-postgres-out` は、ダイアグラムが保持する各レコードを PostgreSQL または TimescaleDB のテーブルの 1 行として書き込みます。postgres ノードがすでに使っている `hotloop-flow-postgres` サーバーを通します。レコードのフィールドは同じ名前の列、または指定した列に入り、時刻の列には行が作られた時刻が入ります。ノードを耐久にすると、データベースが取りこぼした行はディスクに書かれ、データベースが戻ったときに、再起動をまたいでも順番に挿入されます。バックログは 1 文あたり 256 行で書き込まれます。私たちのテストでは、毎秒 100 件で 5 分に相当する 30,000 行がディスクで待機し、データベースが戻った 5 秒から 7 秒後にすべて順番に書き込まれました。すでにあるキーなど、中身が理由でデータベースが拒否した行は、その行を含む監査イベント `diagram.row_rejected` とともに破棄されるので、不良な行 1 つでログが止まることはありません。テーブルがない、パスワードが違うといった場合は別で、その行は待ちます。
- **最後の実行のリプレイ(#193)。** ダイアグラムの実行は、最初の 20,000 イベントまで、すべてのノードの開始と終了、ワイヤーを通ったすべての値を記録するようになりました。ダイアグラムバーの「最後の実行のリプレイ」は、選んだ速度でキャンバス上にそれを再生します。`GET /diagrams/{id}/trace` が同じ記録を返し、MCP ツール `get_diagram_trace` がそれを読みます。デプロイ以降に実行されていないダイアグラムは 404 を返します。記録は最後の実行のもので、再起動をまたいでは保持されません。
- **英語に加えて 13 言語(#192)。** エディタ、ノードの名前、ラベル、ヘルプ、ダッシュボードのページが、英語に加えて、スペイン語、フランス語、イタリア語、ドイツ語、ノルウェー語ブークモール、ブルガリア語、ギリシャ語、韓国語、日本語、ベトナム語、ヒンディー語、簡体字中国語、アラビア語(右から左)で使えます。ピッカーはエディタにあり、初回の訪問ではブラウザの言語に従います。言語にまだ用意されていないテキストは英語で表示されます。翻訳はネイティブスピーカーによる確認を経ていない初稿で、一部は確認対象として印が付いています。
- **FlowLab のロードマップ**(ロードマップ、フェーズ 9)は、2.10.0 以降に出荷された FlowLab の作業を完了として示すようになりました。まだ開いている項目は、Pi での丸一日の運用だけです。

## 変更点

- ダイアグラムバーに、最後の実行のリプレイボタン、リプレイ停止ボタン、速度の選択が加わりました。ダイアグラムの実行やデバッグについて、ほかに変わったことはありません。
- MCP エンドポイントが提供する Flow 自身のツールは、40 から 41 になりました。`get_diagram_trace` が新しいものです(#190 がダイアグラムと計測器のツールを加え、今ではすべての管理ルートがツールか、人が行う必要があるものとしてテストに明記されています)。
- `LICENSE`、`NOTICE`、readme のバッジ、チャートのメンテナーは、HotLoop Source License Agreement 1.0 のもとで HotLoop LLC をライセンサーおよびメンテナーとし、HotLoop の Gold Licensee である EmberNet を連絡先 `helpdesk@fireballz.ai` として示すようになりました(#186、#188)。条件はライセンス自身のもので、動作は変わりません。これらのファイルはイメージの中に入っています。
- MQTT の再接続は、ブローカーが応答または拒否するまで、待ち時間を延ばしながら各サブスクリプションを再送します。以前は一度だけ送ってエラーを捨てていました(#180)。負荷のかかったブローカーでタイムアウトした接続が、接続されたまま応答しなくなることはなくなりました。
- 新しいノードは、ほかのすべての FlowLab ノードと同じく、キャンバス上に描かれた `db` の記号を付けています。
- 静的バイナリは 51,757,218 バイト(49 MiB)で、言語カタログのために 46 MiB から引き上げた `ci.yml` の 50 MiB の予算内に収まっています。
- テストとドキュメントのみ: タイミングのテストは sleep ではなく時計で判定し(#191)、フローのダッシュボードはある環境からエクスポートして別の環境へそのままインポートでき(#189)、Flow が 2026-11-17 に実機で動いたので readme のハードウェアに関する注記を閉じ(#182)、readme は顧客名を出さずに Flow の現在地を述べています(#183)。

## 新しい設定

ありません。

## アップグレード

2.15.0 のイメージとチャートへの単純な `helm upgrade`、または Quadlet ユニットの新しいタグです。初回起動で起きることはなく、移行も不要です。フローファイルは以前どおりバイト単位で読み込み、保存されます。このリリースは amd64 のみです。arm64 のマシンは 2.15.1 まで 2.14.1 のままで、2.15.1 は arm64 イメージを加えた同じコードです。こちらにある言語を求めるブラウザは、初回の訪問でその言語を受け取り、ピッカーで変更できます。

イメージ: `ghcr.io/hotloop-io/hotloop-flow:2.15.0`、まずlinux/amd64で、arm64は2.15.1で続きます。チャート: `https://hotloop.io/hotloop-flow/`。このタグのREADMEに残りが写真つきであります: https://github.com/HotLoop-io/hotloop-flow/blob/v2.15.0/README.md
