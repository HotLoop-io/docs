HotLoop Flow 2.17.2 は 2.17.1 を arm64 に届けます。1 つのイメージで、x86 のマシンも、64 ビットの Raspberry Pi や ARM エッジゲートウェイのような arm64 のマシンもカバーします。コード、チャート、設定、お使いのフローに変更はありません。

## 変更点

- イメージは linux/amd64 と linux/arm64 向けにビルドされます。タグ `2.17.2`、`2.17`、`2` は両方を含みます。
- README とインストールページは 2.17.2 を示し、amd64 と arm64 に対応していると記載します。

## 新しい設定

ありません。

## アップグレード

2.17.2 のイメージとチャートへの通常の `helm upgrade`、または Quadlet ユニットの新しいタグで更新できます。チャートはイメージのタグを自身のバージョンから取るため、2.17.1 のチャートをインストールした arm64 のマシンは、イメージを得るために 2.17.2 に移ります。arm64 で 2.16.1 にとどまっていた場合は、これが移行のタイミングです。それ以降の新機能は 2.17.1 のノートをご覧ください。初回起動で起きることはなく、移行も不要です。

イメージ: `ghcr.io/hotloop-io/hotloop-flow:2.17.2`、linux/amd64。Chart: `https://hotloop.io/hotloop-flow/`。このタグのREADMEに残りが図つきであります: https://github.com/HotLoop-io/hotloop-flow/blob/v2.17.2/README.md
