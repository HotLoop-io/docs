このリリースには、4.23.0 のノートに挙げられたすべてが含まれます。天気とエネルギー、さらに 13 言語に対応した Web UI、ファイルとしてインストール間を移動する画面、そして UniFi コンソールへの最初のコマンドです。amd64 のみでビルドされています。マルチアーキテクチャビルドは次のバージョンで続きます。

## 変更点

- **気象ステーションは 1 つのエンティティです。** 屋根の上のステーションがすでに公開しているタグ(温度、湿度、気圧、風、雨、日射)から作られ、露点、ヒートインデックス、風冷えはボックス上で計算されます。ステーションに与えられていないセンサーには行がなく、応答しなくなったセンサーはゼロではなく Unavailable と読まれます。クラウドサービスは呼び出しません。[Weather](/ja/iot/weather/)をご覧ください。
- **エネルギーメーター。** メーターは、使用量として読まれるタグです(kWh、ガス、水、空気のような累積カウンター、または電力)。使用した量は 15 分のバケットで保持されるため、再起動しても何も失われず、シフト、1 日、1 か月は合計です。料金表はバケットが作られるときに各バケットにコストを与えるため、あとで価格を変えても先月のコストは変わらず、生産した単位あたりのコストは生産メーターから計算されます。Energy 画面、API、MCP ツールがあります。[Energy](/ja/iot/energy/)をご覧ください。
- **Web UI が英語に加えてさらに 13 言語で使えます。** スペイン語、フランス語、イタリア語、ドイツ語、ノルウェー語、ブルガリア語、ギリシャ語、韓国語、日本語、ベトナム語、ヒンディー語、簡体字中国語、そして右から左に表示されるアラビア語です。上部のバーかサインインカードで選びます。[Languages](/ja/iot/languages/)をご覧ください。
- **ダッシュボードをファイルにエクスポートし、別のインストールにインポートできます。** 顧客の画面は顧客のものであり、製品の一部ではありません。ファイルには、それが参照するすべてのタグ、デバイス、スクリプト、レシピが一覧され、インポートは何かを保存する前に、名前が異なる場合のマッピングとともに、すべての問題を一度に報告します。Export と Import は Dashboards 画面のボタンで、`screen_export` と `screen_import` は MCP ツールです。[Screen files](/ja/iot/screen-file/)をご覧ください。
- **書き込みと対になる MCP の読み取り**、エディターのドライラン、CODESYS のアラームインポートです。
- **UniFi コンソールへの最初のコマンド。** 5 種類のポイントに命令でき、それぞれは人がそのタグを有効にするまで読み取り専用で、ほかのタグと同じく書き込みゲートを通ります。デバイスの位置確認 LED、デバイスの再起動、スイッチポートの PoE 電源サイクル、無線ネットワークのオンとオフ、監視中のクライアントのブロックと解除、ポートの PoE モードです。電源サイクルにはデータベースに保持される 15 分のクールダウンがあり、再起動しても忘れず、ネットワークを運ぶポート(アップリンク、スイッチ、ゲートウェイ、5G バックアップ、コンソールが一覧にしないピア)は決してサイクルされません。HotLoop がサインインするコンソールのアカウントは、これらにはローカルの Administrator である必要があり、View Only のアカウントはコンソールに拒否され、HotLoop がそう伝えます。組み込みの blueprint は、応答のないデバイスのポートを一度サイクルし、そのあとアラームを上げます。[UniFi Network](/ja/iot/unifi/)をご覧ください。
- **OPC UA サーバーが HistoryRead に応答します。** Gateway が保持する履歴から、生の値と処理済みの値を返します。
- **OPC UA PubSub の delta フレームをオプションで。** `HOTLOOP_UADP_PUBLISH_DELTA_FRAMES=true` で、key フレームの間に変わったフィールドだけを送ります。既定ではオフです。
- **パネルページの画像カードがカードに収まり、** 行の高さを決めなくなりました。
- **Quadlet インストールのデータベースアップグレードユニットは、ボリュームにアップグレードするものがなければ自分自身をスキップします。** Podman 5.7 は実行するものがないコンテナーを起動しないためで、同梱のデータベースの名前は StatefulSet が持てる 52 文字に合わせられました。
- **チャートはアンインストール時に認証情報の Secret を残します。** データベースのボリュームと同じです。同じ名前での再インストールは、残ったデータベースが拒否する新しいパスワードを生成していました。クリーンに始めるには、ボリュームとともに Secret を手で削除してください。
- **Kafka 出力は、** 作られたばかりの topic について、接続が許す限りブローカーを待ち、Edge Relay の文書化された停止時キューの数値は実測値です(毎秒 2,000 件の読み取りで約 2 分)。
- テストスイートが見つけた修正:OPC UA のテストユーザーは bcrypt の最低コストでハッシュされるため、スイート内のログインが、遅いランナーでテストクライアントが待つ時間を超えなくなりました(サーバーとそのログインは変わりません)。ライブフィードは、最後のページが去った瞬間に送ったものを忘れます。OPC UA サーバーは、リスナーがポートを保持しているときにそう伝えます。そして、いくつかのテストは、それ自身の時間で起きることを sleep で待たなくなりました。

## マイグレーション

2 つで、どちらも追加のみです。`0028_unifi_port_cycles`(各スイッチポートが最後に電源サイクルされた時刻)と `0029_energy`(メーターとそのバケットのための 3 つのテーブル)です。どちらもバックアップに含まれます。4.22.1 で取ったバックアップはここで復元でき、ここで取ったバックアップは古いリリースには復元できません。

## API の変更

新しいルート:`GET /api/energy/meters`、`POST /api/energy/meters`、`GET`、`PUT`、`DELETE /api/energy/meters/{id}`、`GET /api/energy/summary` と `/api/energy/summary/{period}`、`GET /api/energy/series` と `/api/energy/series/{meter}/{period}/{step}`、`GET /api/dashboards/{id}/export`、`POST /api/dashboards/import`、`GET /api/entities/composites`。新しい権限が 2 つ:すべてのロールが持つ `energy.read` と、管理者が持つ `energy.write` です。それぞれに新しい MCP ツールがあります。気象ステーションは新しいエンティティドメイン `weather` です。[HTTP API](/ja/iot/api/)をご覧ください。

## 4.22.1 からのアップグレード

通常の `helm upgrade` です。マイグレーションは初回起動時に実行されてテーブルを追加し、新しい secret はありません。オフだったものがオンになることはありません。

## 検証していないこと

- そのほかのコマンドは、実際のコンソールに対して実行していません。
- 天気とエネルギーは、録画データ、Modbus の試験装置、Emberburn のシミュレートされたカウンターに対して実行したもので、実際の屋根のステーションやプラントのメーターではありません。
- 13 の新しい言語カタログは共通の用語集から書かれたもので、ネイティブスピーカーによるレビューは受けていません。
