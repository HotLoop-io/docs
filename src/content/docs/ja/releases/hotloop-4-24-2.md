HotLoop は、あらゆる世代の Shelly デバイスを直接読み取って制御し、ONVIF カメラを見つけてそのストリームとスナップショット、パン・チルト・ズームを提供し、Firmata で Arduino と通信し、仕様が求める方法で任意の長さの OPC UA パスワードを送ります。低速な回線がエッジノードをディスクに縛りつけることはなくなり、`--version` はイメージのビルド元のコミットを示します。HotLoop Edge の既定のインストールが起動します。amd64 のみでビルドしており、マルチアーキテクチャのビルドは次のバージョンで続きます。

## 変更点

- **あらゆる世代の Shelly。** Gen2 以降はライブの websocket を使う RPC で、変化とボタン押下が起きた瞬間に届き、Gen1 は独自の HTTP インターフェイスで読み取ります。ボタン押下はデバイスの下のログブックに記録されます。SHELLY.md を参照してください。
- **ONVIF カメラ。** ネットワーク上のカメラを見つけ(WS-Discovery)、各デバイスの情報、すべてのメディアプロファイルのストリームとスナップショットのアドレス(Media と Media2)、パン・チルト・ズーム、カメラ自身のイベントをタグとログブックの行として読み取ります。プロファイルの現在の画像は、ルート 1 つで取得できます。ONVIF.md を参照してください。
- **Firmata 経由の Arduino。** USB シリアルまたは TCP で、デジタルとアナログのピン、PWM、サーボ、I2C デバイスをタグとして扱います。FIRMATA.md を参照してください。
- **任意の長さの OPC UA パスワード。** 64 バイトを超えるパスワードが、仕様が求める方法(RsaEncryptedSecret、パート 4、7.40.4)で、クライアントからサーバーへ OPC UA 経由で送られるようになり、古いサーバーも引き続きサインインできます。OPC Foundation 自身のスタックを相手に検証済みです。[OPC UA サーバー](/ja/edge/opc-ua-server/)を参照してください。
- **低速な回線がノードをディスクに縛りつけなくなりました。** ディスクの最後の部分を取り込むパスが、その後ろに入ってくるものをメモリから送るようになったため、低速な回線の先の転送キューは空になり、ノードはポーリングのたびに fsync する代わりにディスクから離れます。
- **`--version` がコミットを示します。** すべてのイメージが、バージョンに加えてビルド元のコミットを示します。
- **WebVisu と並べた CODESYS 画面。** CODESYS ビジュアライゼーションのインポートを、実際の WebVisu を相手に同じ PLC 変数で動かして実行し、両者をブラウザーで比較します。
- **docs/legacy のロードマップ行にチェックを入れました。**
- **HotLoop Edge の既定のインストールが起動します。** Pod は、存在しない Secret から Gotify のトークン、Discord の Webhook URL、Discord ボットのトークンを読まなくなりました。それぞれは認証情報が設定されているときだけ送られ、チャートの検査は、レンダーが作らないその Secret へのあらゆる参照を失敗にします。送信先が設定されたチャート、または既存の Secret を指定したチャートは、これまでどおりレンダーされます。
- **双方向の Ignition ラボ。** HotLoop の Ignition での検証が逆方向でも実行されるようになり、ルーターをまたぐマルチキャスト UADP の検証が加わり、最大のレポートのサイズを計測しました。[スケジュールレポート](/ja/gateway/reports/)を参照してください。
- **テストは待つべきものを待ちます。** スマートフォンアプリのウォームアップはサインイン済みのページを待ち、エネルギーのフォームは 1 回の操作でフィールドを埋めます。

## マイグレーション

ありません。

## API の変更

ルートが 2 つ、どちらも新規です。`POST /api/onvif/discover`(`devices.write`)はネットワークで ONVIF カメラを探し、何も追加しません。`GET /api/onvif/{id}/profiles/{profile}/snapshot`(`devices.read`)はカメラプロファイルの現在の JPEG を返します。既存のルートは変わっていません。[HTTP API](/ja/iot/api/)を参照してください。

## 4.24.0 からのアップグレード

通常の `helm upgrade` です。マイグレーションも新しい secret もありません。

## 検証していないこと

- Shelly、ONVIF、Firmata は、実機の録画、ONVIF 自身の生成スタック、シミュレートした Uno 上の Arduino プロジェクト自身の StandardFirmata を相手に実行しました。実機の Shelly、カメラ、Arduino はまだベンチに載っていません。
- WebVisu との並べた比較は、CODESYS Control for Linux SL 4.22.0.0 ランタイムを相手にテストで実行されます。
