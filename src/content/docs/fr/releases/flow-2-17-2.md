HotLoop Flow 2.17.2 apporte la 2.17.1 à arm64. Une seule image couvre désormais vos machines x86 et vos machines arm64, comme un Raspberry Pi 64 bits ou une passerelle edge ARM. Rien ne change dans le code, le chart, les réglages ou vos flux.

## Ce qui a changé

- L'image est construite pour linux/amd64 et linux/arm64. Les tags `2.17.2`, `2.17` et `2` contiennent les deux.
- Le README et les pages d'installation nomment la 2.17.2 et indiquent amd64 et arm64.

## Nouveaux réglages

Aucun.

## Mise à jour

Un simple `helm upgrade` vers l'image et le chart 2.17.2, ou le nouveau tag dans votre unité Quadlet. Le chart prend son tag d'image dans sa propre version : une machine arm64 avec une installation du chart 2.17.1 passe donc à la 2.17.2 pour obtenir son image. Si vous êtes en arm64 et êtes resté en 2.16.1, c'est votre étape ; lisez les notes de la 2.17.1 pour tout ce qui est nouveau depuis. Rien ne se passe au premier démarrage et rien n'est à migrer.

Image : `ghcr.io/hotloop-io/hotloop-flow:2.17.2`, linux/amd64. Chart : `https://hotloop.io/hotloop-flow/`. Le README à ce tag a le reste, avec des images : https://github.com/HotLoop-io/hotloop-flow/blob/v2.17.2/README.md
