HotLoop for CODESYS, c'est HotLoop à côté d'un runtime CODESYS. EmberNet le package et le déploie depuis l'App Store, et la documentation EmberNet couvre ce côté.

Où il se trouve dans la documentation EmberNet :

- [HotLoop for CODESYS sur EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-codesys)
- [Présentation de l'App Store](https://docs.embernet.ai/docs/app-store/overview)
- [HotLoop Gateway sur EmberNet](https://docs.embernet.ai/docs/app-store/hotloop)
- [HotLoop Edge sur EmberNet](https://docs.embernet.ai/docs/app-store/hotloop-edge)

La page Gateway couvre aussi HotLoop Transmitter, la bibliothèque CODESYS qui publie en OPC UA PubSub.

[Utiliser HotLoop en entreprise](/fr/business/) couvre les licences et la façon de nous joindre.

Retour à la [présentation de HotLoop for CODESYS](/fr/codesys/overview/), ou à la [page HotLoop for CODESYS sur hotloop.io](https://hotloop.io/codesys/).
