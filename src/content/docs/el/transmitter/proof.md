Αυτή η σελίδα είναι η εκτέλεση του 1.0.0. Η εκτέλεση του 1.1.0, με χρονοσφραγίδες και το `.package`, βρίσκεται στις [σημειώσεις έκδοσης 1.1.0](/el/releases/transmitter-1-1-0/). Έκτοτε η βιβλιοθήκη έχει τρέξει σε υλικό χωρίς λειτουργικό σύστημα (2026-11-17).

## Το build

* Βιβλιοθήκη: μεταγλωττίζεται με 0 σφάλματα και 0 προειδοποιήσεις στο ScriptEngine του CODESYS 3.5.22.30 (SP22 Patch 3).
* Εφαρμογή παραδείγματος, χτισμένη με την εγκατεστημένη βιβλιοθήκη, για τη συσκευή CODESYS Control for Linux SL (4102, 0000 0005, 4.20.0.0): 0 σφάλματα, 0 προειδοποιήσεις, έτοιμη για λήψη.

## Το runtime

Το CODESYS Control for Linux SL 4.22.0.0 φορτώνει την εφαρμογή ως boot project και αναφέρει `Application started`, `CODESYS Control ready`. Τρέχει σε demo λειτουργία, επειδή δεν υπάρχει άδεια runtime.

## Τι πέρασε από τη γραμμή και ποιος το διάβασε

Η εφαρμογή παραδείγματος έχει δύο publishers: writer group 1 και dataset writer 1 σε κωδικοποίηση Variant (1142 bytes), και writer group 2 και dataset writer 2 σε κωδικοποίηση RawData (1144 bytes). Δεκαεπτά πεδία το καθένα: ένα από κάθε τύπο που υποστηρίζει η βιβλιοθήκη, ένας πίνακας REAL 250 στοιχείων, ένας πίνακας INT 4 στοιχείων και δύο μετρητές.

## Πίνακες και strings RawData

Αυτή η βιβλιοθήκη γράφει ένα πλήθος στοιχείων Int32 πριν από κάθε πίνακα RawData, και ένα string ως μήκος Int32, τα bytes του και μετά padding με μηδενικά μέχρι το MaxStringLength. Αυτό κάνει η στοίβα αναφοράς του OPC Foundation, και ακολουθεί το κείμενο της προδιαγραφής: OPC 10000-14 7.2.4.5.11 ("handled like a Structure DataType", padding "to the maximum size indicated by ArrayDimensions or MaxStringLength") με το OPC 10000-6 5.2.5 ("One dimensional Arrays are encoded as a sequence of elements preceded by the number of elements encoded as an Int32 value").

Ο subscriber του HotLoop core και ο δεύτερος αποκωδικοποιητής διαβάζουν και οι δύο τους πίνακες RawData με αυτόν τον τρόπο, με το μήκος και το padding, και αποκωδικοποιούν και οι δύο το RawData αυτής της βιβλιοθήκης.

Μία διαφορά από τη στοίβα αναφοράς: εκεί που εκείνη ρίχνει εξαίρεση όταν ένα string είναι μακρύτερο από το MaxStringLength, αυτή η βιβλιοθήκη το κόβει σε όριο χαρακτήρα, επειδή ένα task PLC δεν έχει πού να ρίξει εξαίρεση.

## Τι πρέπει να ξέρετε

* Η εκτέλεση έγινε σε CODESYS Control for Linux SL 4.22.0.0 σε x86-64. Η βιβλιοθήκη είναι Structured Text, και ο χειρισμός της σειράς των bytes για στόχο big endian είναι γραμμένος, και τον ελέγχετε στον δικό σας ελεγκτή.
* Multicast: το block ορίζει το TTL, το loopback και τη διεπαφή αποστολής για μια ομάδα multicast. Ελέγξτε την ομάδα στο δικό σας δίκτυο.
* Το block μετράει τις αποτυχίες αποστολής και κάνει αναμονή όταν το δίκτυο χαθεί ή μια διεύθυνση δεν υπάρχει, και το πρόγραμμα συνεχίζει να σαρώνει.
* Σε demo λειτουργία το runtime σταματά στο τέλος του διώρου παραθύρου του, όπως λέει το CODESYS.
