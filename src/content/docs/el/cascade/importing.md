---
title: "Εισαγωγή μιας ροής εργασίας"
description: "Εισαγάγετε μια υπάρχουσα ροή εργασίας στο Cascade: τι μεταφέρεται και τι σας λέει ο εισαγωγέας ότι δεν μπόρεσε να μεταφέρει."
---

Η εντολή `hotloop-cascade workflows convert export.json -o workflow.yaml --report report.json` μετατρέπει μια ροή εργασίας που εξήχθη ως JSON από άλλο εργαλείο. Μεταφέρει όσα μπορεί να γνωρίζει με βεβαιότητα: τα βήματα που αναγνωρίζει και τις αναγνώσεις πεδίων στις ρυθμίσεις τους. Όλα τα υπόλοιπα έρχονται απενεργοποιημένα, με τις αρχικές τους ρυθμίσεις στις σημειώσεις τους, και η αναφορά απαριθμεί το καθένα και τον λόγο. Δεν μετατρέπει ποτέ μια έκφραση JavaScript σε εικασία για το τι σήμαινε και δεν φέρνει ποτέ διαπιστευτήρια, επειδή μια εξαγωγή δεν τα περιέχει: η αναφορά λέει ποια υποδοχή χρειάζεται ποια. Στη συνέχεια η εντολή `workflows import workflow.yaml` την εισάγει.
