Η διεπαφή ιστού του HotLoop IoT, του Edge και του Gateway (και του HotLoop for CODESYS, που τρέχει τη διεπαφή του Edge) διατίθεται στα αγγλικά και σε 13 ακόμη γλώσσες: ισπανικά (es), γαλλικά (fr), ιταλικά (it), γερμανικά (de), νορβηγικά μποκμόλ (nb), βουλγαρικά (bg), ελληνικά (el), κορεατικά (ko), ιαπωνικά (ja), βιετναμέζικα (vi), χίντι (hi), απλοποιημένα κινεζικά (zh-Hans) και αραβικά (ar, από δεξιά προς αριστερά).

Διαλέξτε μία στο πλαίσιο γλώσσας της επάνω γραμμής ή στην κάρτα σύνδεσης. Η επιλογή διατηρείται σε αυτό το πρόγραμμα περιήγησης. Αν δεν επιλεγεί τίποτα, η σελίδα χρησιμοποιεί την πρώτη από τις γλώσσες του προγράμματος περιήγησης που έχει το HotLoop, και αγγλικά αν δεν ταιριάζει καμία. Μια γλώσσα εμφανίζεται στην επιλογή μόνο όταν το αρχείο της είναι πλήρες.

Ό,τι ακολουθεί τη γλώσσα: κάθε λέξη σε κάθε οθόνη, η σειρά και τα σημεία των αριθμών (υποδιαστολή με κόμμα στα γερμανικά, γαλλικά και ισπανικά), οι ημερομηνίες και οι ώρες (ρολόι 24 ωρών), οι μορφές πληθυντικού (τα αραβικά έχουν έξι) και η κατεύθυνση της σελίδας. Τα ονόματα προϊόντων και πρωτοκόλλων (HotLoop, Modbus, OPC UA, MQTT, Sparkplug, CODESYS, UniFi) μένουν όπως είναι γραμμένα. Οι τιμές από το εργοστάσιο, όπως τα ονόματα των tag, τα ονόματα συσκευών, τα μηνύματα συναγερμού που έγραψε κάποιος και το κείμενο σφάλματος που στέλνει πίσω ο διακομιστής, εμφανίζονται ως έχουν.

## Πώς λειτουργεί

* Το [i18next](https://www.i18next.com/) 27 βρίσκει το μήνυμα, συμπληρώνει το `{{name}}` και επιλέγει τον πληθυντικό. Ρωτά το `Intl.PluralRules` του ίδιου του προγράμματος περιήγησης, άρα οι κανόνες πληθυντικού είναι του Unicode CLDR. Οι αριθμοί και οι ημερομηνίες χρησιμοποιούν τα `Intl.NumberFormat` και `Intl.DateTimeFormat` μέσω του `web/src/lib/format.ts`.
* Τα μηνύματα βρίσκονται στο `web/src/i18n/locales/<language>.json`, σε επίπεδη μορφή, ένα κλειδί ανά μήνυμα. Το `en.json` είναι η πηγή. Κάθε άλλο αρχείο έχει ακριβώς τα ίδια κλειδιά.
* Σε ένα πρότυπο ή ένα script γράψτε `tl('area.key')` ή `tl('area.key', { name })`. Ένα μήνυμα με πλήθος έχει ένα κλειδί για κάθε μορφή πληθυντικού (`key_one`, `key_other`, και `key_few`, `key_many`, `key_two`, `key_zero` όπου μια γλώσσα τα έχει) και ζητείται με το απλό κλειδί και το `count`: `tl('overview.tags_count', { count: n })`.
* Τα αγγλικά είναι μέρος της σελίδας. Μια άλλη γλώσσα είναι ξεχωριστό αρχείο, που φορτώνεται όταν κάποιος τη διαλέξει.
* Το `web/src/i18n/index.svelte.ts` κρατά τη γλώσσα· η αλλαγή της ξαναζωγραφίζει κάθε οθόνη. Μια λέξη που βρίσκεται σε σταθερά στην κορυφή ενός αρχείου `.ts` διαβάζεται μία φορά όταν φορτώνεται το αρχείο και δεν μεταφράζεται: γράψτε την ως getter (`get label() { return tl('x.y'); }`) ή κρατήστε το κλειδί και καλέστε το `tl()` εκεί όπου ζωγραφίζεται.
* Η σελίδα ορίζει το `<html lang dir>`. Το CSS χρησιμοποιεί λογικές ιδιότητες (`margin-inline-start`, `inset-inline-end`, `text-align: start`), άρα η διάταξη γυρίζει μόνη της για τα αραβικά.

## Προσθήκη ή αλλαγή μιας λέξης

1. Προσθέστε το μήνυμα στο `en.json` και γράψτε το στον κώδικα με `tl()`.
2. Προσθέστε το σε κάθε άλλο αρχείο γλώσσας, γραμμένο από άνθρωπο που διαβάζει τη γλώσσα, ακολουθώντας την κοινή βάση όρων στο codex (`work/notes/i18n/glossary/`). Σύντομες, απλές προτάσεις. Τα ονόματα προϊόντων και πρωτοκόλλων μένουν στα αγγλικά.
3. Τρέξτε `cd web && npm run check:i18n`. Αποτυγχάνει όταν σε ένα αρχείο γλώσσας λείπει ένα κλειδί, έχει διαφορετικό `{{placeholder}}` από τα αγγλικά ή λείπει μια μορφή πληθυντικού που χρειάζεται η γλώσσα του· όταν ένα κλειδί δεν χρησιμοποιείται· και όταν αγγλικά γράφονται σε πρότυπο ή σε κώδικα χωρίς να περνούν από το `tl()`. Τρέχει πριν από κάθε `npm run build` και στο `npm run typecheck`, άρα η πλήρης σουίτα και το build της έκδοσης σταματούν εκεί. Τα αγγλικά που πρέπει να μείνουν (ένα όνομα, ένα παράδειγμα κώδικα) μπαίνουν στο `web/i18n/allow.json` με τον λόγο.

Ορίστε τα `HOTLOOP_TEST_BROWSER_GALLERY` και `HOTLOOP_TEST_BROWSER_ARTIFACTS` για να κρατήσετε ένα στιγμιότυπο από καθεμία.

## Τι δεν μεταφράζεται

* Το κείμενο που στέλνει ο διακομιστής: τα μηνύματα σφάλματος του API, τα μηνύματα ειδοποιήσεων και συναγερμών, και το CLI. Η διεπαφή τα δείχνει όπως έρχονται.
* Η τεκμηρίωση, τα ονόματα του διακομιστή OPC UA, ο broker MQTT και οι τιμές του chart Helm.
