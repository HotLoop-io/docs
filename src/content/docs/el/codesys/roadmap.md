Αυτή είναι η λίστα με ό,τι έχει γίνει και ό,τι απομένει, με τη σειρά που γίνεται. Δεν υπόσχεται τίποτα που δεν υπάρχει στον κώδικα ή σε ένα σχέδιο δοκιμών, και η σελίδα [Πού βρίσκεται](/el/codesys/where-it-stands/) λέει πόσο μακριά έχει τρέξει.

## Χτίστηκε

- [x] Ένα chart γύρω από το HotLoop Edge με προεπιλογές για runtime σε κόμβο: SQLite, ένα replica, ανοχές που κρατούν και τα δύο pods όταν χαθεί το control plane.
- [x] Ένας provisioner που εφαρμόζει ένα προφίλ και το κρατά σωστό, με μια αναθεώρηση που προστατεύει ό,τι άλλαξε ένας άνθρωπος.
- [x] Ένα προφίλ που μεταφέρει λίστα συσκευών οποιουδήποτε πρωτοκόλλου μιλά το HotLoop, ώστε ένας listener να επιστρέφει ρυθμισμένος χωρίς να χρειάζεται PLC.
- [x] Η συσκευή, τα tags, ο συναγερμός και η οθόνη φτιαγμένα χωρίς χειροκίνητο βήμα, απέναντι σε runtime CODESYS Control for Linux SL 4.22.0.0 σε container.
- [x] Ανάκαμψη από επανεκκίνηση του runtime χωρίς παρέμβαση, σε περίπου 88 δευτερόλεπτα.
- [x] Μια υπογεγραμμένη σύνδεση από το dashboard του EmberCORE, με τις απορρίψεις.

## Κυκλοφόρησε

- [x] HotLoop 4.22.0, η έκδοση που τυλίγει το chart.
- [x] Το chart δημοσιευμένο στο `https://hotloop.io/hotloop-codesys/`, με το 0.3.8 ως το νεότερο.
- [x] Η εικόνα του provisioner δημόσια, ώστε να κατεβαίνει χωρίς σύνδεση, 0.3.3.
- [x] Εικόνα provisioner πολλαπλών αρχιτεκτονικών, amd64 και arm64, από το 0.3.3 και το chart 0.3.8.
- [x] Δύο listeners OPC UA PubSub σε μία θύρα UDP, με HotLoop 4.22.0 και chart 0.3.7.
- [x] [Σημειώσεις έκδοσης](/el/releases/codesys-0-3-8/) για κάθε chart, 0.3.0 έως 0.3.8.

## Αποδείχθηκε σε υλικό χωρίς λειτουργικό σύστημα

- [x] Τρέχτηκε σε υλικό χωρίς λειτουργικό σύστημα (2026-11-17), συμπεριλαμβανομένης μιας εγκατάστασης από την πραγματική σελίδα του App Store όπως τη κάνει το προσωπικό, k3s v1.35.7, ενός κόμβου που πραγματικά χάνει τη σύνδεσή του με το control plane με τα pods να διατηρούνται, μιας λήψης από το IDE του CODESYS ενώ το runtime μένει ενεργό, ενός runtime στο δικό του δίκτυο του host δίπλα στο pod του HotLoop σε έναν κόμβο, και ενός runtime με ενεργή διαχείριση χρηστών και endpoint OPC UA ασφαλισμένο με πιστοποιητικό.
