Τι θα γίνει το HotLoop Flow, με τη σειρά που χτίζεται. Αν κάτι δεν είναι σε αυτή τη λίστα, δεν πρόκειται να γίνει, οπότε βάλτε το στη λίστα.

Το Flow χτίζεται δίπλα στο HotLoop και μένει ξεχωριστό προϊόν. Το FlowLab και τα διαγράμματά του, η Φάση 9, είναι ένα ξεχωριστό πακέτο που στέκεται δίπλα στη μηχανή μηνυμάτων.

## Σε τι χρησιμεύει το Flow

Μια οπτική μηχανή ροών για το εργοστασιακό δάπεδο. Κάθε ανάπτυξη συγκρίνεται, δοκιμάζεται και απέχει ένα κλικ από την επαναφορά. Όταν κάτι στραβώσει στις 3 τα ξημερώματα, βλέπετε ακριβώς ποιον δρόμο πήρε ένα μήνυμα και πώς ήταν σε κάθε βήμα. Τρέχει σε ένα στατικό εκτελέσιμο, αρκετά μικρό για ένα Pi, και δεν καταρρέει όταν ένας αισθητήρας γίνεται φλύαρος.

Διαβάζει επίσης τα υπάρχοντα `flows.json` σας αναλλοίωτα. Είναι πρόσθετο προσόν, όχι ο σκοπός.

Οι κανόνες με τους οποίους παραδίδεται κάθε σημείο παρακάτω:

- Χωρίς προσωρινές λύσεις. Αν δεν έχει χτιστεί, δοκιμαστεί με το πραγματικό και λειτουργεί, δεν τσεκάρεται.
- Ό,τι μπορεί να δώσει εντολή σε εξοπλισμό περνά από μια πύλη που μπορεί να πει όχι, και λέει γιατί.
- Τίποτα δεν πετιέται αθόρυβα. Κάθε απόρριψη, άρνηση και υπερχείλιση μετριέται και φαίνεται στις μετρήσεις.
- Το αρχείο ροών συνεχίζει να φορτώνεται και να αποθηκεύεται byte προς byte. Τα νέα δεδομένα μπαίνουν σε κλειδιά που τα άλλα εργαλεία αγνοούν, και η δοκιμή μετ' επιστροφής καλύπτει αρχεία που τα φέρουν.

### Φάση 1: ιστορικό, διαφορές, επαναφορά

Κάθε ανάπτυξη είναι μια εγγραφή: ποιος, πότε, μια σημείωση, τα ακριβή byte και τι άλλαξε. «Τι άλλαξε, ποιος το άλλαξε, βάλτε το πίσω» είναι το πρώτο που ρωτά όλος ο κόσμος αφού σταματήσει μια γραμμή, και σήμερα η απάντηση είναι τρία αρχεία `.bak`.

- [x] Αρχείο αναπτύξεων: κάθε ανάπτυξη είναι μια αμετάβλητη εγγραφή με τον χρήστη, την ώρα, μια προαιρετική σημείωση, τα byte της ροής και τα κρυπτογραφημένα διαπιστευτήρια όπως ήταν. Η διατήρηση είναι ρύθμιση. `GET /deployments`
- [x] Σημασιολογική διαφορά: κόμβο προς κόμβο, ιδιότητα προς ιδιότητα. Προστέθηκε, αφαιρέθηκε, άλλαξε, επανασυνδέθηκε. Η μετακίνηση ενός κόμβου εμφανίζεται ως διάταξη, ποτέ ως αλλαγή λογικής. Μέσω του API και ως `hotloop-flow diff a.json b.json`
- [x] Η διαφορά λειτουργεί ως difftool του git, ώστε ένα pull request σε μια ροή να γράφει «κατώφλι του κανόνα 2 από 7,5 σε 8,0» αντί για ένα μπλοκ JSON
- [x] Επαναφορά: αναπτύσσει ξανά μια παλιά εγγραφή ως νέα, με τα διαπιστευτήρια, ώστε ένας κόμβος που διαγράψατε να επιστρέφει με τον κωδικό του broker του. Το ιστορικό μένει μόνο για προσθήκες
- [x] Επεξεργαστής: πάνελ ιστορικού, η διαφορά σχεδιασμένη στον καμβά, «έλεγχος και ανάπτυξη» με σημείωση, κουμπί επαναφοράς. Μια σύγκρουση ανάπτυξης δείχνει τι άλλαξε ο άλλος αντί για ένα πλαίσιο ναι/όχι
- [x] Ροές ως κώδικας: `hotloop-flow deploy` και `hotloop-flow export` για CI/CD, με token μόνο για ανάπτυξη, ώστε ένα pipeline να μη κρατά ποτέ κωδικό διαχειριστή
- [x] Προαιρετικός καθρέφτης git: κάθε ανάπτυξη ωθείται ως commit με συγγραφέα αυτόν που ανέπτυξε. Καθαρό Go, και ο έλεγχος μεγέθους του εκτελέσιμου εξακολουθεί να περνά
- [x] Αρχείο ελέγχου: συνδέσεις, αποτυχημένες συνδέσεις, αναπτύξεις, επαναφορές και inject, το καθένα με ποιος και από πού. Το αρχείο αναπτύξεων είναι ο πρώτος του πίνακας
- [x] MFA (TOTP), δωρεάν και ενεργή για όποιον τη θέλει. Τίποτα που αφορά την ασφαλή σύνδεση δεν χρεώνεται ποτέ
- [x] Περιορισμός προσπαθειών σύνδεσης και κλείδωμα, συνεδρίες που επιβιώνουν από επανεκκίνηση, και το token του websocket που στέλνεται ως υποπρωτόκολλο αντί για το URL. Ένα token στο URL εξακολουθεί να δουλεύει για τα υπάρχοντα scripts και καταγράφει προειδοποίηση, γιατί το σπάσιμό τους σε μια αναβάθμιση ήταν χειρότερο από τη διαρροή· η αφαίρεσή του περιμένει μια μείζονα έκδοση

### Φάση 2: δοκιμές ροών

Το «Χάλασε η αλλαγή μου τη γραμμή;» απαντιέται πριν από την ανάπτυξη, όχι μετά. Οι δοκιμές είναι YAML δίπλα στις ροές, ώστε να συγκρίνονται και να ελέγχονται με τον ίδιο τρόπο.

- [x] `hotloop-flow test`: το πραγματικό runtime και οι πραγματικοί κόμβοι, στην ίδια διεργασία. Εισάγετε ένα μήνυμα, περιμένετε ό,τι βγαίνει από μια θύρα μέσα σε προθεσμία, περιμένετε τίποτα, περιμένετε ένα σφάλμα να φτάσει σε ένα Catch. Έξοδος JUnit για CI/CD
- [x] Εικονικοποιημένο I/O: ένα MQTT out, μια εγγραφή σε βάση ή ένα αίτημα HTTP σε μια δοκιμή καταγράφει τι θα είχε στείλει και δεν αγγίζει ποτέ το δίκτυο
- [x] Εικονικό ρολόι: ένα Delay πέντε λεπτών τρέχει σε χιλιοστά του δευτερολέπτου, και κάθε κόμβος χρονισμού αποδεικνύεται απέναντί του
- [x] Fixtures context και διαπιστευτηρίων, και ισχυρισμοί για το context μετά. Μια δοκιμή δεν μπορεί να στηριχτεί σε ό,τι άφησε μια άλλη
- [x] Πύλη ανάπτυξης: όταν είναι ενεργή, μια ανάπτυξη που αποτυγχάνει στις δοκιμές της απορρίπτεται με τους ισχυρισμούς που αποτυγχάνουν, και οι ροές που ήδη τρέχουν δεν το καταλαβαίνουν
- [x] Επεξεργαστής: μετατρέψτε ένα καταγεγραμμένο μήνυμα αποσφαλμάτωσης σε δοκιμή με δύο κλικ, τρέξτε τη σουίτα από τον επεξεργαστή, με επιτυχία και αποτυχία πάνω στους κόμβους

### Φάση 3: ιχνηλάτηση και επανάληψη

### Φάση 4: ανθεκτική κατάσταση

Ένας historian που πέφτει για μία ώρα δεν πρέπει να σας κοστίζει μία ώρα μετρήσεων.

- [x] Επίμονο context σε SQLite, καθαρό Go χωρίς cgo, με τις ατομικές λειτουργίες (σύγκριση και ανταλλαγή, αύξηση, ενημέρωση). Ένας χώρος αποθήκευσης για το context τώρα και για τις ανθεκτικές ουρές μετά, όχι δύο. Σήμερα το context ροής και το καθολικό χάνονται σε κάθε επανεκκίνηση, που είναι το κενό που πιθανότερα θα δαγκώσει πρώτο κάποιον. Γράφεται με καθυστέρηση σε μία συναλλαγή ανά τριάντα δευτερόλεπτα, και μια τιμή που τίθεται σε ό,τι ήδη ήταν δεν γράφει τίποτα
- [x] Ανθεκτικές συνδέσεις: σημειώστε μια σύνδεση ως ανθεκτική και η ουρά της ξεχειλίζει στον ίδιο χώρο αντί να μπλοκάρει ή να απορρίπτει. Επιβιώνει από επανεκκίνηση, κρατά τη σειρά, τηρεί ποσοστό δίσκου, και το βάθος είναι μέτρηση. Σημειώνεται στο αρχείο ροών με `ew_durable`, ώστε η μετ' επιστροφής αναπαραγωγή να μένει ακριβής στο byte. Κάντε διπλό κλικ σε μια σύνδεση στον επεξεργαστή για να τη σημειώσετε
- [x] Αποθήκευση και προώθηση αποδεδειγμένη με τον δύσκολο τρόπο: σκοτώστε το πραγματικό InfluxDB για δέκα λεπτά υπό σταθερή είσοδο, φέρτε το πίσω, μετρήστε γραμμές. Καμία δεν λείπει, καμία δεν διπλασιάστηκε. Μετά kill -9 στο runtime στη μέση της ουράς και νέα μέτρηση. Το script, οι μετρήσεις και οι εγγραφές δίσκου ανά ώρα είναι στο [durable/](/el/flow/durable-state/)
- [x] Αποδεδειγμένο σε πραγματικό Pi 5: μνήμη, χρόνος εκκίνησης και διατηρούμενη απόδοση, στο [docs/bench](/el/flow/benchmarks/#αποτελέσματα-σε-raspberry-pi-5), με τον περιορισμό ταχύτητας που έδειξε
- [ ] Αποδεδειγμένο σε Pi 4 και Zero 2 W, και οι εγγραφές ανά ώρα σε κάρτα SD, γιατί ένας χώρος context που φθείρει μια κάρτα SD είναι σφάλμα. Ανοιχτό γιατί χρειάζονται οι πλακέτες. Το Pi 5 έχει μετρηθεί· ένας αριθμός από άλλο μηχάνημα θα ήταν επινοημένος

### Φάση 5: το εργοστασιακό δάπεδο

Το `scan` βρίσκει σήμερα ένα PLC και τίποτα στην παλέτα δεν μπορεί να του μιλήσει. Είναι η μεγαλύτερη τρύπα σε ένα προϊόν φτιαγμένο για εργοστάσια.

- [x] Modbus TCP ανάγνωση και εγγραφή
- [x] OPC UA ανάγνωση, συνδρομή και εγγραφή
- [x] S7 ανάγνωση και εγγραφή
- [x] Sparkplug B, ως edge node και ως host
- [x] EtherNet/IP ανάγνωση και εγγραφή
- Όλα σε προσομοιωτές. Κανένα CPU Siemens ή controller Logix δεν έχει βρεθεί μπροστά σε κάτι από αυτά
- [x] Κόμβοι HotLoop: αλλαγές οντοτήτων ως είσοδος, κατάσταση οντότητας, κλήση ενός script, εφαρμογή μιας συνταγής. Κάθε εντολή περνά από την πύλη εγγραφής του HotLoop και καταλήγει στο ημερολόγιό του ως `flow:<node id>`, και μια εγγραφή που η πύλη αρνείται φτάνει σε κόμβο Catch με τον λόγο της πύλης
- [x] Όταν το HotLoop είναι εκεί, οι εγγραφές του Flow σε εξοπλισμό περνούν από την πύλη του HotLoop αντί να πηγαίνουν κατευθείαν στο PLC. Και τα δύο βγήκαν στην 2.3.0. Μια εγγραφή μέσω της πραγματικής πύλης είναι αποδεδειγμένη για Modbus απέναντι σε δημοσιευμένο image του HotLoop· οι κόμβοι εγγραφής OPC UA, S7 και EtherNet/IP στέλνουν μέσω του ίδιου κώδικα και μια δοκιμή ελέγχει ότι ο καθένας προσφέρει την πύλη.

### Φάση 6: plugins χωρίς npm

- [x] Ένας κόμβος `wasm` στον host που ήδη υπάρχει: αυστηρό όριο μνήμης, χρονικό όριο, και ένας guest που ξεπερνά το ένα ή το άλλο σταματά χωρίς να παρασύρει τίποτα άλλο
- [x] Μορφή plugin: το module, ένας descriptor ώστε ο επεξεργαστής να σχεδιάζει το παράθυρό του, και μια υπογραφή. Plugins χωρίς υπογραφή ή παραποιημένα αρνούνται να φορτώσουν και λένε γιατί
- [x] Δυνατότητες: ένα plugin δεν έχει πρόσβαση στον host εκτός αν το ζητά το manifest του και την παραχωρεί ο χειριστής. Το αίτημα για κάτι μη παραχωρημένο αποτυγχάνει την ανάπτυξη

### Φάση 7: τυποποιημένες συνδέσεις και MCP

- [x] Επικύρωση σχήματος στον κόμβο `json`, το πρώτο κομμάτι
- [x] Προαιρετικά σχήματα στις θύρες. Μια ασυμφωνία που βλέπει ο επεξεργαστής απορρίπτεται στην ανάπτυξη· μια που δεν βλέπει πηγαίνει σε κόμβο Catch με τη διαδρομή του λανθασμένου πεδίου, και σε μια μέτρηση
- [x] Τύποι σχεδιασμένοι πάνω στις συνδέσεις στον επεξεργαστή
- [x] Ροές ως εργαλεία MCP: ένας κόμβος εργαλείου δηλώνει όνομα, περιγραφή και σχήμα εισόδου, και το Flow σερβίρει `/mcp`. Ένας agent που καλεί μια ροή παίρνει τα ίδια δικαιώματα και το ίδιο αρχείο ελέγχου με έναν άνθρωπο
- [x] Ένας κόμβος client MCP, ώστε μια ροή να καλεί εργαλεία άλλων servers, και του HotLoop
- [x] Τα δικά του εργαλεία MCP του Flow: λίστα, ανάγνωση, ανάπτυξη και επαναφορά ροών, λίστα των αναπτύξεων και πάτημα ενός κόμβου inject, μέσω των ίδιων των χειριστών του API διαχείρισης με τα ίδια δικαιώματα, ελέγχους ανάπτυξης και ίχνος ελέγχου, επειδή ένα MCP που θα μπορούσε να καλεί μόνο ό,τι έχει συνδέσει ο συγγραφέας μιας ροής δεν θα μπορούσε ούτε να διαβάσει ούτε να γράψει το ίδιο το Flow
- [x] Τα δικά του εργαλεία MCP του Flow για διαγράμματα και όργανα: λίστα και ανάγνωση των διαγραμμάτων, εκτέλεση και διακοπή ενός, χειρισμός του debugger του, ρύθμιση ενός ελέγχου στο πάνελ του, ορισμός σημείων διακοπής και ανιχνευτών, δημιουργία υποδιαγράμματος, και ανάγνωση και εναλλαγή των εγγραφών ενός οργάνου, το καθένα ως διαδρομή διαχείρισης που εκτελείται από τον δικό της χειριστή με το δικαίωμα που ζητά αυτή η διαδρομή (`status.read`, `diagram.run`, `instrument.write`). Μέχρι τώρα οι διαδρομές διαγραμμάτων δεν είχαν εργαλείο, οπότε ένας agent μπορούσε να αναπτύξει ένα διάγραμμα και να μην το εκτελέσει. Κάθε διαδρομή διαχείρισης είναι τώρα εργαλείο ή κατονομάζεται σε δοκιμή ως μία που πρέπει να κάνει άνθρωπος, και η δοκιμή αποτυγχάνει όταν προστεθεί νέα διαδρομή χωρίς εργαλείο. Τώρα υπάρχουν 44 εργαλεία, με αυτά για σταθμούς, failover και ίχνη

### Φάση 8: ο επεξεργαστής, ξαναγραμμένος σε Astro

Έγινε, και προωθήθηκε. Επρόκειτο να είναι τελευταίος, και τον φέραμε πριν από τα πρώτα στιγμιότυπα οθόνης του Flow, γιατί κανείς δεν πρέπει να βλέπει τα πρώτα σε έναν επεξεργαστή που μοιάζει να είναι από άλλη εταιρεία.

Κάθε έργο του HotLoop παίρνει ένα σύγχρονο UI, και αυτός ο επεξεργαστής ήταν αυτός που δεν ταίριαζε. Ήταν χειροποίητο vanilla TypeScript πάνω σε εγγενές SVG, που ήταν η σωστή επιλογή όταν ο στόχος ήταν ένα μικρό στατικό εκτελέσιμο χωρίς τίποτα να ελεγχθεί. Τώρα είναι Astro με νησίδες Svelte, η ίδια στοίβα με τον επεξεργαστή του Cascade, πάνω στα ίδια tokens του HotLoop, φωτεινό και σκοτεινό.

- [x] Πρώτα ένας γύρος σχεδιασμού, πριν από μία γραμμή Astro. Πώς πρέπει να φαίνεται και να αισθάνεται ο επεξεργαστής δίπλα στα υπόλοιπα του HotLoop, κλεισμένο στο χαρτί και στα κοινά tokens, ώστε η ανακατασκευή να χτίζει κάτι που κάποιος έχει ήδη αποφασίσει αντί να αποφασίζει στην πορεία
- [x] Ο επεξεργαστής ξαναχτισμένος σε Astro με τον καμβά, τα παράθυρα, το ιστορικό, τον έλεγχο, τις δοκιμές, την ιχνηλάτηση, την αναζήτηση και τις ομάδες μεταφερμένα, και κανένα να μην χειροτερεύσει. Οι δοκιμές προγράμματος περιήγησης στο `web/e2e` είναι το μέτρο: περνούν απέναντι στον νέο επεξεργαστή αμετάβλητες
- [x] Ακόμα ενσωματωμένος στο ένα στατικό εκτελέσιμο, ακόμα χωρίς ανάγκη δικτύου σε ένα edge box, ακόμα εντός του προϋπολογισμού μεγέθους του εκτελέσιμου, και η πύλη αδειών καλύπτει ακόμα ό,τι αποστέλλεται στο bundle

Ο καμβάς και το γράφημα από κάτω δεν ξαναγράφτηκαν. Μετακινήθηκαν στο `web/src/lib` ως το TypeScript που ήταν, με νέα όψη, ώστε η σύνδεση, το σύρσιμο, η αναίρεση και η μετ' επιστροφής αναπαραγωγή του αρχείου ροών ακριβώς στο byte να είναι ο κώδικας που ήταν ήδη δοκιμασμένος. Όλα γύρω του είναι Svelte.

Το Flow μένει ξεχωριστό προϊόν σε όλο αυτό. Μοιράζεται την εμφάνιση με το HotLoop, όχι τον κώδικα, και δεν ενσωματώνεται ποτέ στο HotLoop.
