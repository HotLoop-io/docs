Μόνο απόλυτοι αριθμοί. Ένας πίνακας σύγκρισης μετακινείται κάθε φορά που αλλάζει το κουτί και καταλήγει να περιγράφει το άλλο περισσότερο από αυτό.

Το Flow απαντά σε περίπου 15.000 αιτήματα το δευτερόλεπτο σε επιτραπέζιο και περίπου 13.000 το δευτερόλεπτο σε Raspberry Pi 5, με λιγότερα από 30 MiB μνήμης στο επιτραπέζιο και 42 MiB στο Pi. Αυτός είναι ο λόγος ύπαρξης μιας μηχανής ροών αρκετά μικρής για το κουτί στο εργοστάσιο.

## Η ροή

Πέντε κόμβοι: ένα σημείο HTTP, τρεις επεξεργασίες ιδιοτήτων, μια απάντηση. Τίποτα σε αυτήν δεν είναι γρήγορο επίτηδες. Είναι το σχήμα μιας μικρής πραγματικής ροής, που είναι το αντικείμενο που πρέπει να έχει ένα τεστ επιδόσεων μηχανής ροών. Ο παραγωγός φορτίου είναι κλειστού βρόχου: κάθε πελάτης στέλνει το επόμενο αίτημα όταν επιστρέψει το προηγούμενο, οπότε μετρά ό,τι μπορεί να απορροφήσει η άλλη άκρη και δεν μπορεί να παράγει την παραπλανητική καθυστέρηση που αναφέρει ένας παραγωγός ανοιχτού βρόχου όταν ο στόχος μένει πίσω.

## Τρέξτε το μόνοι σας

Το `hotloop-flow bench` έρχεται μέσα στο εκτελέσιμο. Το `-launch` ξεκινά το εκτελέσιμο, μετρά πόσο χρόνο χρειάζεται μέχρι να απαντήσει η ροή (ψυχρή εκκίνηση), διαβάζει την προσωρινή μνήμη της διεργασίας δύο δευτερόλεπτα αργότερα (αδράνεια), και μετά τη δειγματοληπτεί κατά τη διάρκεια του φορτίου και κρατά την κορύφωση. Το `-target` χωρίς `-launch` οδηγεί μέσω HTTP ένα στιγμιότυπο που ήδη τρέχει, ένα κοντέινερ ή ένα pod, για διεκπεραίωση και καθυστέρηση.

```bash
hotloop-flow bench -mode http -launch ./hotloop-flow -target http://127.0.0.1:18897 -path /bench -duration 30s -warmup 5s -connections 8
hotloop-flow bench -mode engine -chain 5 -messages 200000
```

## Αποτελέσματα

Μετρήθηκε σε επιτραπέζιο x86 (24 CPU), με το εγγενές στατικό εκτελέσιμο, τρεις εκτελέσεις η καθεμία.

| <span class="sr-only">Λεπτομέρειες</span> | Εκτέλεση 1 | Εκτέλεση 2 | Εκτέλεση 3 |
|---|---|---|---|
| Ψυχρή εκκίνηση | 0.05 s | 0.05 s | 0.05 s |
| RSS, αδράνεια | 16.7 MiB | 16.7 MiB | 16.4 MiB |
| RSS, κορύφωση υπό φορτίο | 26.4 MiB | 26.4 MiB | 28.5 MiB |
| Διεκπεραίωση HTTP | 15.0k req/s | 15.3k req/s | 13.0k req/s |
| Καθυστέρηση HTTP p50 / p95 / p99 | 0.39 / 1.22 / 1.82 ms | 0.39 / 1.20 / 1.78 ms | 0.41 / 1.49 / 4.03 ms |
| Μηχανή, ανά μήνυμα | 2.61 µs | 3.11 µs | 2.20 µs |
| Μηχανή, μνήμη που διατίθεται ανά μήνυμα | 3,868 bytes | 3,869 bytes | 3,868 bytes |

## Αποτελέσματα σε Raspberry Pi 5

Μετρήθηκε σε ένα Raspberry Pi 5 των 8 GB, με το ρολόι του περιορισμένο στα 2.0 GHz, ως pod στο k3s, χωρίς τίποτα άλλο στον κόμβο. Η ίδια ροή, τρεις εκτελέσεις, η καθεμία σε νέο pod.

| <span class="sr-only">Λεπτομέρειες</span> | Εκτέλεση 1 | Εκτέλεση 2 | Εκτέλεση 3 |
|---|---|---|---|
| Ψυχρή εκκίνηση | 0.46 s | 0.15 s | 0.10 s |
| RSS, κορύφωση υπό φορτίο | 40.3 MiB | 40.5 MiB | 40.3 MiB |
| Διεκπεραίωση HTTP | 13.2k req/s | 13.4k req/s | 13.3k req/s |
| Καθυστέρηση HTTP p50 / p95 / p99 | 0.48 / 1.45 / 2.78 ms | 0.48 / 1.42 / 2.72 ms | 0.48 / 1.44 / 2.74 ms |
| Μηχανή, ανά μήνυμα | 8.15 µs | 7.74 µs | 7.89 µs |

Με συνεχή λειτουργία 600 δευτερολέπτων, η ίδια εντολή στην ίδια πλακέτα σταθεροποιείται στα 11.4k req/s με p50 στα 0.58 ms και p99 στα 3.00 ms. Η πλακέτα λειτουργεί με απλή ψήκτρα χωρίς ενεργή ψύξη και επιβραδύνεται υπό τόσο φορτίο, οπότε αυτός είναι ο τίμιος αριθμός για ένα κουτί που μένει φορτωμένο.

### Τι δεν είναι αυτοί οι αριθμοί

**Η διεκπεραίωση HTTP περιλαμβάνει τη στοίβα HTTP.** Επίτηδες: είναι ό,τι βιώνει ένας πελάτης της ροής σας. Δεν είναι μέτρηση του χρονοπρογραμματιστή. Οι γραμμές της μηχανής είναι, χωρίς καθόλου I/O στη διαδρομή.

**Ένα σχήμα ροής, ένα μέγεθος περιεχομένου, μία ταυτοχρονία.** Μια ροή με πραγματικό I/O, μια δημοσίευση MQTT ή μια εγγραφή σε βάση δεδομένων, κυριαρχείται από αυτό το I/O. Αυτοί οι αριθμοί είναι το δικό του κόστος του χρόνου εκτέλεσης, όχι υπόσχεση για κάθε φόρτο εργασίας.

**Η ουρά κινείται περισσότερο από τη διάμεσο.** Υπό κορεσμό όλα περιμένουν σε ουρά και η ουρά κυριαρχεί στο p99. Η διάμεσος είναι εκεί που φαίνεται το κόστος της εξυπηρέτησης ενός αιτήματος.

**Αυτή είναι η ροή του τεστ, όχι τα ανθεκτικά καλώδια.** Τίποτα εδώ δεν μετρά τον χώρο αποθήκευσης πίσω από ένα ανθεκτικό καλώδιο ή τις εγγραφές σε κάρτα SD.

## Μνήμη

Το RSS είναι η δική της μνήμη της διεργασίας, διαβασμένη από το `/proc`. Δεν είναι ό,τι αναφέρει το `podman stats`, που δείχνει ό,τι χρεώνει ο πυρήνας στο κοντέινερ και μπορεί να δείχνει πολύ λιγότερα από όσα πραγματικά κρατά η διεργασία.
