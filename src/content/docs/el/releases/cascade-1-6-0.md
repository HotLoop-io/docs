## Τι είναι αυτό

Η 1.6.0 είναι η έκδοση όπου το Cascade παύει να είναι απλώς ένα μέρος όπου τρέχουν ροές εργασίας και γίνεται ένα μέρος όπου συμμετέχουν άνθρωποι, μοντέλα και άλλοι διακομιστές. Μια εκτέλεση μπορεί να σταματήσει και να ρωτήσει ένα άτομο στο κινητό. Μια εκτέλεση μπορεί να ρωτήσει ένα μοντέλο που είναι δικό σας. Οι ροές εργασίας σας μπορούν να ζουν στο Git και μια εγκατάσταση παραγωγής μπορεί να αρνείται να επεξεργάζεται με το χέρι. Και κάθε web API μπορεί να γίνει βήματα από ένα αρχείο. Η μηχανή, η μορφή αρχείου και όλα τα άλλα είναι όσα έχει η 1.5.1.

## Ρωτήστε ένα άτομο, από το κινητό

Το νέο βήμα Ζήτηση έγκρισης σταματά την εκτέλεση και περιμένει. Βάλτε το `execution.approvalUrl` σε μια ειδοποίηση push, και όποιος τη λάβει την πατά, διαβάζει όσα γράψατε, συμπληρώνει μια μικρή φόρμα αν φτιάξατε και πατά Έγκριση ή Απόρριψη. Η σελίδα είναι απλή, γρήγορη, δεν ζητά σύνδεση εκτός αν το ζητήσετε, και μιλά τη γλώσσα του προγράμματος περιήγησης και στις δεκατέσσερις. Η εκτέλεση συνεχίζει από το Εγκρίθηκε ή το Απορρίφθηκε με το ποιος απάντησε, πότε και τι είπε. Κάθε απάντηση είναι εγγραφή: στον επεξεργαστή πάνω στην εκτέλεση, στο API στο `GET /api/v1/approvals`, στον διακομιστή MCP ως `list_approvals` και στο αρχείο ελέγχου. Κάντε το βήμα να απαιτεί συνδεδεμένο λογαριασμό και δέχεται απαντήσεις μόνο από τους λογαριασμούς που αναφέρετε. Ένας σύνδεσμος λειτουργεί μία φορά. Η αναμονή δεν κοστίζει τίποτα, οπότε μια απάντηση μπορεί να έρθει μια εβδομάδα αργότερα και να επιβιώσει από κάθε επανεκκίνηση.

## Ρωτήστε ένα μοντέλο

Δύο νέα βήματα, ΤΝ: ρώτα ένα μοντέλο και ΤΝ: εκτέλεσε έναν πράκτορα. Το μοντέλο είναι δικό σας: ένα διαπιστευτήριο δείχνει σε διακομιστή που τρέχετε εσείς (Ollama, vLLM, llama.cpp) ή σε φιλοξενούμενη υπηρεσία για την οποία έχετε κλειδί, με το πρωτόκολλο του OpenAI ή της Anthropic. Τίποτα δεν πηγαίνει εκεί που δεν ορίζει το διαπιστευτήριο, δεν υπάρχει φιλοξενούμενη υπηρεσία και κάθε κλήση περνά από την πολιτική εξόδου όπως κάθε άλλη. Το Ρώτα ένα μοντέλο βάζει την απάντηση στο στοιχείο, ως κείμενο ή ως αντικείμενο JSON που ταιριάζει σε σχήμα που δίνετε. Το Εκτέλεσε έναν πράκτορα δίνει στο μοντέλο έναν στόχο και μια λίστα εργαλείων όπου κάθε εργαλείο είναι άλλη ροή εργασίας σας. Ζητά ένα, το Cascade το εκτελεί, επιστρέφει το αποτέλεσμα, και αυτό επαναλαμβάνεται μέχρι το μοντέλο να απαντήσει ή να τελειώσουν οι γύροι. Ανάμεσα στους γύρους η εκτέλεση περιμένει στη βάση δεδομένων, οπότε ένα αργό εργαλείο δεν δεσμεύει κανέναν worker.

## Ροές εργασίας στο Git

Συνδέστε ένα έργο με ένα αποθετήριο, έναν κλάδο και έναν φάκελο, και κάντε push ή pull. Το push γράφει ένα αρχείο ανά ροή εργασίας, με το όνομά της και το αναγνωριστικό της, και το κάνει commit ως το άτομο που έκανε push με το μήνυμα που έδωσε. Το pull ευθυγραμμίζει το έργο με το αποθετήριο: τα νέα αρχεία γίνονται ροές εργασίας (απενεργοποιημένες μέχρι να τις ενεργοποιήσετε), τα αλλαγμένα αρχεία γίνονται νέες εκδόσεις, τα αναγνωριστικά διατηρούνται ώστε μια ροή να είναι η ίδια σε κάθε εγκατάσταση, και μια αλλαγή που έγινε και στις δύο πλευρές αναφέρεται και μένει ανέγγιχτη εκτός αν πείτε ποιος κερδίζει. Οι διαγραφές γίνονται μόνο όταν τις ζητήσετε. Υπάρχει μια κάρτα σε κάθε έργο, έξι διαδρομές API και έξι εργαλεία MCP. Μιλά HTTPS με όνομα χρήστη και token ή κωδικό φυλαγμένο στο θησαυροφυλάκιο, μέσω της πολιτικής εξόδου.

## Προστατευμένες εγκαταστάσεις

Δώστε όνομα σε μια εγκατάσταση (ανάπτυξη, δοκιμές, παραγωγή) και εμφανίζεται σε ένα σήμα στο πάνω μέρος κάθε οθόνης. Προστατέψτε την, από τις Ρυθμίσεις ή με το `HOTLOOP_CASCADE_PROTECTED` (η τιμή `protected` του chart, που καμία ρύθμιση δεν μπορεί να αναιρέσει), και οι ροές της δεν μπορούν να δημιουργηθούν, να επεξεργαστούν, να επαναφερθούν ή να διαγραφούν με το χέρι στον επεξεργαστή, το API ή το MCP. Έρχονται με pull από το Git. Τα διαπιστευτήρια, οι μεταβλητές, οι εκτελέσεις και η ενεργοποίηση ή απενεργοποίηση μιας ροής μένουν ανοιχτά, επειδή διαφέρουν από περιβάλλον σε περιβάλλον. Μια προστατευμένη εγκατάσταση κάνει pull και δεν κάνει push.

## Σύνδεσμοι ως αρχεία

Ένας σύνδεσμος είναι ένα αρχείο που λέει πού είναι ένα API, πώς γίνεται η σύνδεση και τι δέχεται και τι απαντά κάθε κλήση. Βάλτε το στο `HOTLOOP_CASCADE_CONNECTORS_DIR` (ο φάκελος `connectors` στον κατάλογο δεδομένων) και κάθε λειτουργία είναι ένα βήμα, με φόρμα, δικό της τύπο διαπιστευτηρίου, σελιδοποίηση και επαναλήψεις ταξινομημένες όπως τις ταξινομούν οι ενσωματωμένοι σύνδεσμοι. Η μορφή είναι δημοσιευμένη, με εκδόσεις, και έχει JSON Schema (`hotloop-cascade connector schema`). Τα εργαλεία για να γράψετε έναν βρίσκονται στο εκτελέσιμο: `connector init`, `validate`, `call` (δοκιμή μιας λειτουργίας πάνω στο πραγματικό API) και `index` και `install` για κοινοποίηση, όπου ένα ευρετήριο είναι στατικά αρχεία με ένα hash το καθένα. Το Cascade δεν κατεβάζει ποτέ ευρετήριο που δεν ονομάσατε. Ο διακομιστής MCP έχει τώρα 91 εργαλεία.

## Επιστροφή

Αυτή η έκδοση προσθέτει τρεις πίνακες (εγκρίσεις και δύο για το Git) και οι μεταναστεύσεις πάνε μόνο προς τα εμπρός, οπότε η επιστροφή στην 1.5.1 χρειάζεται το αντίγραφο ασφαλείας που κάνατε πριν την αναβάθμιση, όχι μόνο την παλιά εικόνα. Τίποτα υπάρχον δεν αλλάζει μορφή.
