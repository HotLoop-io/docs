## Τι είναι αυτό

Το 1.1.0 δίνει στο Cascade έναν διακομιστή MCP και τις οθόνες που έλειπαν από τον επεξεργαστή, και μεταφέρει τη σύνδεση μέσα στον επεξεργαστή. Η μηχανή, η μορφή αρχείου των ροών εργασίας και το REST API είναι όπως στο 1.0.2.

## Ο διακομιστής MCP

Βρίσκεται στο `/mcp`, στην ίδια διεύθυνση με το API, παραδίδεται ενεργός και γράφει. Κάθε MCP της οικογένειας HotLoop διαβάζει και γράφει, και το Cascade ήταν το τελευταίο που δεν είχε καθόλου MCP.

Ένας πράκτορας συνδέεται με ένα κλειδί API και παίρνει όσα θα μπορούσε να κάνει ο κάτοχος του κλειδιού, περιορισμένα στα πεδία πρόσβασης του κλειδιού. Υπάρχουν 79 εργαλεία, και καθένα είναι μια διαδρομή του REST API: μια κλήση περνά από τον δικό της χειριστή της διαδρομής, οπότε ο έλεγχος δικαιωμάτων, η επικύρωση, η εγγραφή και η γραμμή ελέγχου είναι της διαδρομής. Τίποτα δεν αντιγράφηκε στον διακομιστή MCP, οπότε τίποτα δεν μπορεί να αποκλίνει, και τίποτα δεν έμεινε έξω, οπότε τίποτα δεν παραλείπεται.

- Ένα εργαλείο που αλλάζει κάτι ζητά ένα `reason`, και το αρχείο ελέγχου το κρατά δίπλα στην αλλαγή, με το κλειδί και το όνομα που έδωσε στον εαυτό του ο πελάτης.
- Το μυστικό ενός διαπιστευτηρίου δεν επιστρέφει ποτέ, σε κανέναν. Ένα διαπιστευτήριο που δημιουργείται μέσω MCP έχει τα μυστικά του σφραγισμένα μόλις φτάσουν.
- Τα `HOTLOOP_CASCADE_MCP` και `HOTLOOP_CASCADE_MCP_WRITES` είναι οι διακόπτες της ανάπτυξης, και τα δύο ενεργά από προεπιλογή. Κανένα εργαλείο και καμία διαδρομή API δεν μπορεί να τα αλλάξει, οπότε ένας πράκτορας που μπορεί να επεξεργαστεί τις ρυθμίσεις της εγκατάστασης εξακολουθεί να μην μπορεί να ενεργοποιήσει ξανά τις εγγραφές.
- Οι διαδρομές που απορρίπτουν μόνες τους ένα κλειδί (δημιουργία κλειδιών API, token SCIM, παρόχων μυστικών και προορισμών καταγραφής) δεν είναι εργαλεία, επειδή ένα κλειδί που θα μπορούσε να δημιουργεί κλειδιά είναι ένα κλειδί που διέρρευσε και κρατά τον εαυτό του ζωντανό. Η σελίδα MCP τις παραθέτει με κάθε εργαλείο και το δικαίωμα που ζητά.

## Οι οθόνες

Διαπιστευτήρια, Έργα, ο Λογαριασμός σας και, για ιδιοκτήτες και διαχειριστές, Ρυθμίσεις, Χρήστες και το αρχείο ελέγχου. Κάθε μία ακολουθεί τα ίδια δικαιώματα με το API: σε κάθε άτομο προσφέρεται μόνο όσα επιτρέπει ο ρόλος του, και ο διακομιστής εξακολουθεί να απορρίπτει τα υπόλοιπα.

- Τα **Διαπιστευτήρια** δημιουργούνται, ανοίγονται, αλλάζουν, μοιράζονται με άλλα έργα και διαγράφονται. Ένα μυστικό μπαίνει μία φορά και η οθόνη λέει μόνο ότι έχει οριστεί.
- Τα **Έργα** έχουν μέλη και τους ρόλους τους, και τα κλειδιά λογαριασμού υπηρεσίας με τα οποία συνδέεται μια μόνιμη ενσωμάτωση, που εμφανίζονται μία φορά.
- Ο **Λογαριασμός** δημιουργεί και ανακαλεί τα κλειδιά API σας, με τα οποία συνδέονται το API και το MCP, και αλλάζει τον κωδικό σας.
- Οι **Χρήστες** επιτρέπουν να δημιουργείτε άτομα και να τα απενεργοποιείτε ή να τα ενεργοποιείτε. Το **Αρχείο ελέγχου** διαβάζεται, φιλτράρεται και ελέγχεται για παραποίηση. Οι **Ρυθμίσεις** έχουν την απαίτηση δεύτερου παράγοντα και τη ροή εργασίας σφάλματος.

Η σύνδεση είναι πλέον η δική του σελίδα του επεξεργαστή, στο `/login`, με τα χρώματα του επεξεργαστή, φωτεινά και σκούρα, σε κινητό όσο και σε γραφείο. Κάνει ό,τι έκανε η παλιά σελίδα: ρύθμιση πρώτης εκτέλεσης, κωδικούς, λογαριασμούς καταλόγου, ενιαία σύνδεση, passkeys, τον δεύτερο παράγοντα και κωδικούς ανάκτησης.

## Μόνο amd64, και γιατί

Αυτή η έκδοση χτίζεται μόνο για amd64. Η πολυαρχιτεκτονική βγαίνει στη δική της εκτέλεση, οπότε η επόμενη έκδοση είναι μια μικρή αύξηση έκδοσης που χτίζει και τα δύο. Μέχρι τότε τα `stable`, `latest` και οι σύντομες ετικέτες παραθέτουν αυτό το image amd64 δίπλα στο image arm64 στο οποίο ήδη έδειχναν, ώστε ένα μηχάνημα arm να συνεχίζει να τραβά. Η ετικέτα έκδοσης, `1.1.0`, είναι μόνο amd64.

## Αναβάθμιση και επιστροφή

Χωρίς μεταναστεύσεις. `helm upgrade` στο 1.1.0, ή αφήστε το `:stable` να μετακινήσει τις μονάδες Quadlet. Η επαναφορά του 1.0.2 είναι ασφαλής, επειδή τίποτα δεν άλλαξε στη βάση δεδομένων. Αυτό που μια επαναφορά δεν μπορεί να αναιρέσει είναι ό,τι έχει ήδη κάνει ένας πράκτορας: οι αλλαγές του μένουν, και οι γραμμές ελέγχου που έγραψε παραμένουν στο αρχείο με τύπο ενεργού `mcp`. Ένα αντίγραφο ασφαλείας πριν από κάθε ενημέρωση παραμένει καλή συνήθεια.
