## Τι είναι αυτό

Το 1.2.0 ολοκληρώνει τη λίστα εργαλείων του διακομιστή MCP. Η μηχανή, η μορφή αρχείου των ροών εργασίας, οι οθόνες και το REST API είναι όπως στο 1.1.1.

## Τα τέσσερα εργαλεία

Κάθε MCP της οικογένειας HotLoop διαβάζει και γράφει, και το MCP του Cascade είχε αφήσει έξω τέσσερις διαδρομές που ένα κλειδί επιτρέπεται να καλέσει. Είναι πλέον εργαλεία, 83 συνολικά:

- `list_keys` και `revoke_key`: τα κλειδιά του ατόμου στο οποίο ανήκει το κλειδί, και η ανάκληση ενός. Ένα κλειδί μπορεί να ανακαλέσει τον εαυτό του, κάτι που πρέπει να μπορεί να κάνει πρώτα ο κάτοχος ενός κλειδιού που διέρρευσε. Οι δικοί του έλεγχοι της διαδρομής αποφασίζουν ποιανού κλειδιά μπορεί να ανακαλέσει ο καλών, όπως στον επεξεργαστή.
- `listen_workflow`: ανοίγει το URL του δοκιμαστικού webhook μιας ροής εργασίας για μία κλήση, για 1 έως 600 δευτερόλεπτα.
- `start_oauth`: επιστρέφει τη διεύθυνση που ανοίγει ένα άτομο για να συνδεθεί για ένα διαπιστευτήριο OAuth2. Το άτομο πρέπει και πάλι να πει ναι.

Καθένα περνά από τη διαδρομή του, οπότε ο έλεγχος δικαιωμάτων, η επικύρωση και η γραμμή ελέγχου είναι της διαδρομής, και μια εγγραφή ζητά έναν λόγο όπως κάθε άλλο εργαλείο εγγραφής.

## Τι μένει έξω

Δέκα διαδρομές απορρίπτουν μόνες τους ένα κλειδί, επειδή θέλουν ένα συνδεδεμένο άτομο: δημιουργία κλειδιού API ή κλειδιού λογαριασμού υπηρεσίας, δημιουργία token SCIM, προσθήκη, αλλαγή ή διαγραφή παρόχου μυστικών ή προορισμού καταγραφής, και ο δικός σας κωδικός. Ένα κλειδί που θα μπορούσε να δημιουργεί κλειδιά, ή να αλλάζει πού πηγαίνει το αρχείο ελέγχου, είναι ένα κλειδί που διέρρευσε και κρατά τον εαυτό του ζωντανό. Η σελίδα MCP έχει τη λίστα και τον λόγο.

## Μόνο amd64, και γιατί

Αυτή η έκδοση χτίζεται μόνο για amd64. Η πολυαρχιτεκτονική βγαίνει στη δική της εκτέλεση, οπότε η επόμενη έκδοση είναι μια μικρή αύξηση έκδοσης που χτίζει και τα δύο.

## Αναβάθμιση και επιστροφή

Χωρίς μεταναστεύσεις. `helm upgrade` στο 1.2.0, ή αφήστε το `:stable` να μετακινήσει τις μονάδες Quadlet. Η επαναφορά του 1.1.1 είναι ασφαλής, επειδή τίποτα δεν άλλαξε στη βάση δεδομένων. Αυτό που μια επαναφορά δεν μπορεί να αναιρέσει είναι ό,τι έχει ήδη κάνει ένας πράκτορας με τα νέα εργαλεία.
