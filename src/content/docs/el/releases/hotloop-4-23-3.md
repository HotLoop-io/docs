Μια οθόνη WebVisu κρατά την απόκρυψη και τα χρώματα συναγερμού της όταν έρχεται, και κάθε σύμβολο σε κάθε οθόνη μπορεί πλέον να εμφανίζεται και να χρωματίζεται από κανόνα σε ένα tag. Μια μικρή διόρθωση στη λίστα αντιγράφων ασφαλείας ταξιδεύει μαζί της. Χτισμένη μόνο για amd64· το multi-arch build ακολουθεί ως επόμενη έκδοση.

## Τι άλλαξε

- **Ένα σύμβολο μπορεί να εμφανίζεται και να χρωματίζεται από κανόνες.** Το `show` σχεδιάζει ένα σύμβολο μόνο όσο ισχύει ένας κανόνας σε ένα tag, οπότε μια πόρτα, ένα προστατευτικό ή μια αντλία σχεδιασμένα για μία κατάσταση υπάρχουν μόνο σε αυτή την κατάσταση. Το `colors` είναι έως τέσσερις κανόνες, ο καθένας με τόνο (`ok`, `warn`, `bad` ή `info`): ο πρώτος που ισχύει χρωματίζει το σύμβολο σε αυτόν τον τόνο, και όταν δεν ισχύει κανένας σχεδιάζεται όπως ήταν. Ένας κανόνας είναι ένα tag και μια σύγκριση (`on`, `off`, `eq`, `ne`, `gt`, `ge`, `lt`, `le`). Ένας κανόνας του οποίου το tag δεν έχει καλή ένδειξη δεν ισχύει για τίποτα και δεν κρύβει τίποτα, οπότε μια χαμένη σύνδεση δεν κάνει ποτέ ένα σύμβολο να εξαφανιστεί. Η φόρμα συμβόλων του builder έχει και τα δύο, και ένα αρχείο οθόνης απαριθμεί και μετακινεί τα tags των κανόνων μαζί με τα υπόλοιπα. Δείτε [Πίνακες ελέγχου](/el/iot/dashboards/).
- **Η εισαγωγή οθόνης CODESYS φέρει τα Invisible και Toggle color.** Η μεταβλητή Invisible ενός στοιχείου (και της ομάδας του) γίνεται κανόνας `show`, με το `NOT x` να την αντιστρέφει, και η μεταβλητή Toggle color γίνεται κανόνας `colors` στον τόνο που πλησιάζει περισσότερο το δικό του χρώμα συναγερμού του στοιχείου. Βρίσκονται στα ids που δίνουν τα δικά τους δέντρα στοιχείων του CODESYS IDE. Ό,τι δεν μπορεί να φέρει λέγεται στην εισαγωγή, με τη μεταβλητή: αυτά τα δύο σε σχήμα ζωγραφισμένο στην εικόνα φόντου (σωλήνας, δοχείο, πλαίσιο), γιατί η εικόνα είναι μία εικόνα, και κάθε άλλη ρύθμιση που οδηγείται από μεταβλητή (γέμισμα, χρώμα πλαισίου ή κειμένου, κίνηση, αναβόσβημα, λίστα κειμένων). Δείτε [Import a CODESYS screen](/el/iot/codesys-screen-import/).
- **Η λίστα αντιγράφων ασφαλείας δεν αποτυγχάνει ενώ ένα αντίγραφο κλαδεύεται.** Το προγραμματισμένο αντίγραφο κλαδεύει τα παλιά αντίγραφα στη δική του goroutine, και μια λίστα που έπεφτε στη μέση αποτύγχανε στο αρχείο που έλειπε, κάτι που το API απαντούσε ως σφάλμα διακομιστή. Ένα αντίγραφο που έφυγε αφήνεται πλέον έξω από τη λίστα.

## Μεταφορές

Καμία.

## Αλλαγές στο API

Η ρύθμιση ενός συμβόλου δέχεται `show` και `colors`. Καμία διαδρομή δεν άλλαξε. Δείτε [το HTTP API](/el/iot/api/).

## Αναβάθμιση από την 4.23.2

Ένα απλό `helm upgrade`. Καμία μετάβαση δεδομένων και κανένα νέο secret. Ένα σύμβολο χωρίς κανέναν από τους δύο κανόνες σχεδιάζεται όπως πριν.

## Τι δεν έχει αποδειχθεί

- Η εισαγωγή CODESYS αποδείχθηκε απέναντι στη δική του εξαγωγή του IDE μιας οπτικοποίησης και στη μεταβλητή ομάδας του παραδείγματος Refrigerator του CODESYS. Μια οθόνη από άλλο έργο μπορεί να απαριθμήσει περισσότερα που δεν μπόρεσε να τοποθετήσει.
- Οι νέοι κανόνες συμβόλων αποδείχθηκαν από τα τεστ της σουίτας, όχι σε οθόνη εργοστασίου.
