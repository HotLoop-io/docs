## La familia

HotLoop son ocho productos para la planta: cuatro que crecen con el sitio (IoT, Edge, Gateway y Edge Relay), además de Flow para conectar, Cascade para los flujos de trabajo, HotLoop for CODESYS para la pantalla propia del PLC y Transmitter para poner en la red los valores de un PLC. Se publican en cinco líneas de versiones, así que cada una lleva su propia versión. Cada sección de la barra lateral muestra solo lo que ese producto incluye, y un producto mayor enlaza a las páginas que hereda de uno menor.

## Cómo leer esta documentación

**"Verificado" significa que se ejecutó contra lo real:** un servidor OPC UA real, un broker real, el propio Ignition y equipos reales en hardware físico. Ese es el listón de cada afirmación de estas páginas, así que cuando una página dice que un protocolo o una función trabaja, es que se ejecutó.

**La última versión es la que usted tiene instalada.** Una página que describe algo más nuevo que la versión publicada lleva una insignia **Próxima versión** y un recuadro al principio, para que siempre sepa qué hay en su instalación y qué viene.
