---
title: "सोर्स से Flow बिल्ड करना"
description: "Flow बाइनरी को सोर्स से बिल्ड करें: एक स्टैटिक बाइनरी जिसके भीतर एडिटर है और नीचे कोई C लाइब्रेरी नहीं।"
---

HotLoop Flow एक स्टैटिक बाइनरी है जिसके भीतर एडिटर है, इसलिए ज़्यादातर लोग प्रकाशित इमेज खींच लेते हैं और कभी कुछ बिल्ड नहीं करते। अगर आप अपना बिल्ड चाहते हैं, तो सोर्स सार्वजनिक है, और बिल्ड के लिए Go और Node चाहिए।

```bash
cd web && npm install && npm run build && cd ..
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o hotloop-flow ./cmd/hotloop-flow
```

नतीजा स्टैटिक है, नीचे कोई C लाइब्रेरी नहीं, इसलिए यह ऐसी distroless इमेज पर चलता है जिसमें और कुछ इंस्टॉल नहीं होता। हर Flow रिलीज़ एक वर्शन टैग से बनती है और किसी और चीज़ से नहीं, इसलिए आपके प्लांट की इमेज हमेशा ऐसी होती है जिसका आप नाम ले सकते हैं और जिसे किसी रिलीज़ तक खोज सकते हैं।
