यह इस बात की सूची है कि क्या हो चुका है और क्या बाक़ी है, उसी क्रम में जिसमें वह होता है। यह ऐसा कुछ वादा नहीं करती जो कोड या टेस्ट योजना में न हो, और [स्थिति](/hi/codesys/where-it-stands/) बताती है कि इसे कितनी दूर तक चलाया गया है।

## बनाया गया

- [x] नोड पर रनटाइम के लिए डिफ़ॉल्ट वाला HotLoop Edge के चारों ओर चार्ट: SQLite, एक रेप्लिका, ऐसी टॉलरेशन जो कंट्रोल प्लेन खोने पर भी दोनों पॉड रखती हैं।
- [x] एक प्रोविज़नर जो प्रोफ़ाइल लागू करता है और उसे सही रखता है, ऐसे रिविज़न के साथ जो किसी व्यक्ति के बदले हुए की रक्षा करता है।
- [x] एक प्रोफ़ाइल जो HotLoop जिन भी प्रोटोकॉल में बोलता है उनके डिवाइसों की सूची रखती है, ताकि लिसनर बिना PLC के कॉन्फ़िगर होकर लौटे।
- [x] कंटेनर में CODESYS Control for Linux SL 4.22.0.0 रनटाइम के विरुद्ध बिना हाथ लगाए बने डिवाइस, टैग, अलार्म और स्क्रीन।
- [x] रनटाइम रीस्टार्ट से बिना हाथ लगाए रिकवरी, लगभग 88 सेकंड में।
- [x] EmberCORE डैशबोर्ड से हस्ताक्षरित साइन-इन, अस्वीकृतियों के साथ।

## जारी

- [x] HotLoop 4.22.0, वह रिलीज़ जिसे चार्ट लपेटता है।
- [x] `https://hotloop.io/hotloop-codesys/` पर प्रकाशित चार्ट, सबसे नया 0.3.8।
- [x] प्रोविज़नर इमेज सार्वजनिक, ताकि बिना लॉगिन के पुल हो, 0.3.3।
- [x] 0.3.3 और चार्ट 0.3.8 से बहु-आर्किटेक्चर प्रोविज़नर इमेज, amd64 और arm64।
- [x] एक UDP पोर्ट पर दो OPC UA PubSub लिसनर, HotLoop 4.22.0 और चार्ट 0.3.7 के साथ।
- [x] हर चार्ट के लिए [रिलीज़ नोट्स](/hi/releases/codesys-0-3-8/), 0.3.0 से 0.3.8 तक।

## बेयर मेटल पर प्रमाणित

- [x] बेयर मेटल पर चलाया गया (2026-11-17), जिसमें स्टाफ़ की तरह असली App Store पेज से इंस्टॉल, k3s v1.35.7, एक नोड जो पॉड रखते हुए कंट्रोल प्लेन से अपना लिंक सचमुच खोता है, रनटाइम चालू रहते CODESYS IDE से डाउनलोड, एक नोड पर HotLoop पॉड के बगल में होस्ट के अपने नेटवर्क पर रनटाइम, और यूज़र मैनेजमेंट चालू और प्रमाणपत्र से सुरक्षित OPC UA एंडपॉइंट वाला रनटाइम शामिल हैं।
