Cascade 让工厂与其他一切系统对话。一条报警、一个 Webhook、一个计划、一行新数据或一阵 MQTT 消息，都会变成一批条目，这些条目依次经过各个步骤，用真实凭据调用真实系统。如果某个 API 宕机，或设备在中途重启，任务照样能完成，因为每个步骤都有检查点，重试只是数据库里的一行记录。

它是一个静态 Go 二进制文件。在 Raspberry Pi 上用 SQLite，在 k3s 上用 Postgres，worker 想要多少就有多少。队列也是 Postgres，所以工厂集群里没有需要费心照看的 Redis。

## 它不做什么

**它不向您的设备写入。** Cascade 只读取和订阅。任何会让阀门动作或改变设定值的操作，都要经过 HotLoop 的写入闸门，因此无论是哪个工作流发起的，闸门的审计都能看到每一次写入。如果工作流引擎有一扇通向 PLC 的后门，审计记录就不再可信。

**它不在您的字段里运行 JavaScript。** 字段表达式使用 expr，与 HotLoop 自动化所用的是同一种小型语言。它无法接触操作系统、网络或文件系统，而且一定会结束。JavaScript 只存在于一个地方，即 Code 步骤，它在单独的隔离进程中运行，没有密钥、没有网络、没有文件系统。把它挡在其他所有字段之外，也就把远程代码执行挡在了这些字段之外。

**它不限制任何功能。** SSO、强制 MFA、RBAC、审计、版本历史、限定范围的 API 密钥和高可用 worker 全都包含在同一个二进制文件里。代码中任何地方都没有许可证检查。

**它不会向外回传数据。** 没有许可证服务器，不依赖云。遥测需要主动开启，默认关闭，上线时会细化到每个字段并写入文档。
