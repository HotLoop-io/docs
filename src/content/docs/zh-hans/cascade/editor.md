编辑器内置在二进制文件中，因此无需运行其他任何东西，它也不会从任何地方获取任何内容：打开服务器所监听的地址并登录即可。它是带有 Svelte 岛屿的 Astro 应用，在构建镜像时构建为静态文件，颜色和字体与其他所有 HotLoop 界面相同，在您自己选择之前，会跟随系统使用浅色或深色。

![文件夹中的工作流](/synced/cascade/docs/screenshots/workflows.png)

工作流存放在项目中，项目的工作流存放在文件夹里，文件夹可以嵌套得和您的工厂一样深：区域、产线、工位。工作流可以在自己所在的那一行直接移动到其他文件夹。

![画布，选中一个步骤，其设置显示在旁边](/synced/cascade/docs/screenshots/editor.png)
![同一界面的深色模式](/synced/cascade/docs/screenshots/editor-dark.png)

画布还在原来的位置：从输出拖到输入，移动步骤，用 `Ctrl+S` 保存，用 `Delete` 删除步骤。“运行到此处”会不保存、直接运行屏幕上的内容，直到您选中的步骤，并以表格、字段或 JSON 的形式显示它的输出，您还可以固定该输出，这样在构建后面的步骤时，该步骤就不再运行。每个字段都接受表达式，并显示它在最近一次测试运行中的结果。覆盖他人的保存时会收到提示，而不是直接生效。

![一次失败的执行，按实际运行情况绘制](/synced/cascade/docs/screenshots/run.png)

执行会连同每个步骤的结果一起绘制出来。可以从失败的步骤重试，也可以从任意步骤重试，或在编辑器中针对改动进行调试：被重新运行步骤之前的各步骤会保留它们已经做过的事，所以已经发生的写入不会发生两次。事后，任何人都可以在一次执行上留下点赞或点踩、备注和标签，执行记录列表可以按它们查找执行。

![角色](/synced/cascade/docs/screenshots/roles.png)

其余的治理功能都在设置下：角色以及谁拥有这些角色、脱敏策略（工作流在编辑器中从自己的设置里选择一个）、外部密钥提供方、日志转发，以及登录和 SCIM。所有者或管理员可以更改这些；其他人只能读取被允许读取的内容，永远不会看到服务器会拒绝的按钮，而服务器依然会拒绝它。

工作流旁边还有四个界面。凭据在各自的项目中创建、打开、更改、与其他项目共享和删除；密钥字段只输入一次，界面只会显示它已设置。项目显示每个项目里有谁、担任什么角色，以及长期集成用来登录的服务账户密钥。您的账户（顶部栏中的地址）用来创建和撤销您的 API 密钥，REST API 和 MCP 服务器就是用它们登录的，也可以在这里修改密码。对所有者和管理员而言，设置里有常规设置（第二验证因素、错误工作流），用户用来创建和停用人员，还允许所有者删除一个人（其登录和密钥会消失，其工作流会保留），审计日志也在那里读取、筛选并检查是否被篡改。登录页面仍是同一个编辑器，地址是 `/login`，并保留单点登录、目录登录、通行密钥和恢复码。

这对您意味着什么：Cascade 能做的一切，您都可以在这个界面上完成，在没有互联网的工厂设备上，也无需写一行 curl。

编辑器使用站在它面前的人的语言。顶部栏（以及登录页面）上的选择器用每种语言自己的名称列出各个语言，在该浏览器中记住您的选择，首次使用时从浏览器的语言开始。步骤标题及其帮助、凭据类型、按钮、服务器发出的拒绝消息、日期、数字和时长，全都以您选择的语言显示，阿拉伯语从右向左排版，而工作流画布仍和所有人一样从左向右绘制。只有当一种语言的每个词都齐备时，才会提供该语言：`web/src/i18n/check.mjs` 在缺少某一行、占位符或复数形式时让构建失败，`web/scripts/i18n-scan.mjs` 在界面中直接写入文本时让构建失败。文字存放在 `web/src/i18n/locales/<language>/` 中，服务器新增的步骤类型或拒绝消息会由 Go 测试对照检查。执行本身的输出，以及某个步骤调用的程序所说的内容，都按记录时的原样显示。

这对您意味着什么：您的操作员用自己的语言阅读界面，新界面也不可能带着一行没人翻译的英文发布。
