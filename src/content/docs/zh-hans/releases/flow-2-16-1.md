HotLoop Flow 2.16.1 就是加上 arm64 镜像的 2.16.0，没有别的。2.16.0 只发布了 amd64，为的是先进入生产并被标为稳定版，这是同时构建两者的那个小后续版本。代码、chart、设置和您的 flow 都没有变化。

## 变更内容

- 镜像为 linux/amd64 和 linux/arm64 构建。`2.16.1`、`2.16` 和 `2` 标签同时包含两者。
- README 和安装页面写明 2.16.1,并说明支持 amd64 和 arm64。

## 新设置

无。

## 升级

直接 `helm upgrade` 到 2.16.1 的镜像和 chart，或者在您的 Quadlet 单元里换成新标签。chart 的镜像标签取自它自己的版本，所以安装 2.16.0 的 chart 会拉取 amd64 镜像：在 arm64 机器上，请升级到 2.16.1。如果您用的是 arm64，并且在 2.16.0 仅有 amd64 期间一直留在 2.15.1，这就是您该迈出的一步：请阅读 2.16.0 的说明，了解推送到租户站点和热备份是什么，以及哪些尚未证实。首次启动不会发生任何事，也不需要迁移。

镜像：`ghcr.io/hotloop-io/hotloop-flow:2.16.1`，linux/amd64 和 linux/arm64。Chart：`https://hotloop.io/hotloop-flow/`。这个标签的 README 有其余内容，还配有图片：https://github.com/HotLoop-io/hotloop-flow/blob/v2.16.1/README.md
