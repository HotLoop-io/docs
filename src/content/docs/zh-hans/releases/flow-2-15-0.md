HotLoop Flow 2.15.0 给 FlowLab 增加了能保存数据库所丢内容的数据库汇点和已完成运行的回放，把编辑器和节点文本做成英语之外的 13 种语言，并为回放新增一个 MCP 工具。它先发 amd64，arm64 随 2.15.1 跟进。

## 新功能

- **面向 FlowLab 图的 Postgres out（#193）。** 新节点 `dia-postgres-out` 把图中保存的每条记录作为 PostgreSQL 或 TimescaleDB 表的一行写入，通过 postgres 节点已经使用的 `hotloop-flow-postgres` 服务器。记录的字段写入同名的列，或写入你列出的列，时间列得到该行创建的时间。把节点标记为持久，数据库错过的行会被写到磁盘，并在数据库恢复后按顺序插入，即使跨越重启也是如此。积压按每条语句 256 行写入。在我们的测试中，磁盘上等待的 30,000 行，相当于每秒 100 条持续五分钟，在数据库恢复后 5 到 7 秒内全部按顺序写入。数据库因内容而拒绝的行，比如已存在的键，会连同一个携带该行的 `diagram.row_rejected` 审计事件被放弃，所以一个坏行不会让日志停下。缺少表或密码错误则不是这种情况：这些行会等待。
- **回放上一次运行（#193）。** 图的一次运行现在会记录每个节点的开始和结束以及穿过连线的每个值，最多前 20,000 个事件。图栏中的回放上一次运行会以你选择的速度在画布上回放它。`GET /diagrams/{id}/trace` 提供同一份记录，MCP 工具 `get_diagram_trace` 读取它。部署之后没有运行过的图会返回 404。该记录属于上一次运行，重启后不会保留。
- **英语之外的 13 种语言（#192）。** 编辑器、节点名称、标签和帮助，以及仪表板页面，现在提供英语以及西班牙语、法语、意大利语、德语、挪威语书面挪威语、保加利亚语、希腊语、韩语、日语、越南语、印地语、简体中文和阿拉伯语（从右到左）。选择器在编辑器里，首次访问会跟随浏览器的语言。某种语言尚未获得的文本以英语显示。这些翻译是未经母语者审阅的初稿，其中一些已标记待审。
- **FlowLab 的路线图**（路线图，第 9 阶段）现在把自 2.10.0 以来已发布的 FlowLab 工作显示为完成。仍然开着的那一项是在 Pi 上跑一天。

## 变更内容

- 图栏有一个回放上一次运行按钮、一个停止回放按钮和一个速度选项。运行或调试图的其他方面没有任何变化。
- MCP 端点提供 Flow 自带的 41 个工具，比之前的 40 个多一个：`get_diagram_trace` 是新增的（#190 增加了图和仪器工具，现在每条管理路由要么是一个工具，要么在测试中被点名为必须由人来做的）。
- `LICENSE`、`NOTICE`、readme 徽章和图表维护者现在在 HotLoop Source License Agreement 1.0 之下把 HotLoop LLC 列为许可方和维护者，并以 `helpdesk@fireballz.ai` 作为联系方式，对应 HotLoop 的 Gold Licensee EmberNet（#186、#188）。条款是许可证自身的，没有任何行为改变。这些文件随镜像一起发布。
- MQTT 重新连接会重新发送每个订阅，等待时间递增，直到 broker 应答或拒绝，而以前只发送一次并丢掉错误（#180）。在负载很高的 broker 上超时的连接不再保持连接却什么也听不见。
- 新节点在画布上带有一个绘制的 `db` 符号，和其他所有 FlowLab 节点一样。
- 静态二进制为 51,757,218 字节（49 MiB），低于 `ci.yml` 中 50 MiB 的预算，该预算因语言目录从 46 MiB 上调而来。
- 仅限测试和文档：时序测试依据时钟而非 sleep 来判断（#191），流程的仪表板可以从一个安装导出并原样导入到另一个安装（#189），readme 中关于硬件的保留说明已关闭，因为 Flow 于 2026-11-17 在真实硬件上运行过（#182），readme 在不点名客户的情况下说明了 Flow 的现状（#183）。

## 新设置

无。

## 升级

对 2.15.0 的镜像和图表做一次普通的 `helm upgrade`，或在你的 Quadlet 单元里换上新标签。首次启动不会发生任何事，也无需迁移。流程文件和以前一样按字节加载和保存。这个版本仅限 amd64：arm64 机器留在 2.14.1，直到 2.15.1，后者是加上 arm64 镜像的同一份代码。请求我们已有的语言的浏览器在首次访问时就能得到它，选择器可以更改。

镜像：`ghcr.io/hotloop-io/hotloop-flow:2.15.0`，先发布 linux/amd64，arm64 在 2.15.1 中跟进。Chart：`https://hotloop.io/hotloop-flow/`。这个标签的 README 有其余内容，还配有图片：https://github.com/HotLoop-io/hotloop-flow/blob/v2.15.0/README.md
