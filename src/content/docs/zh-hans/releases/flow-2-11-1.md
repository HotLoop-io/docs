HotLoop Flow 2.11.1 就是加上 arm64 镜像的 2.11.0,仅此而已。2.11.0 只发布了 amd64,为的是先进入生产环境并显示为稳定版,而它做到了:有工厂用 13,727 个节点运行它,没有任何重启。这是同时构建两者的小版本升级。代码、chart、设置和您的流程都没有变化。

## 变更内容

- 镜像为 linux/amd64 和 linux/arm64 构建。`2.11.1`、`2.11` 和 `2` 标签都包含两者。
- README 和安装页面写明 2.11.1,并说明支持 amd64 和 arm64。2.11.0 中 README 的安装行仍然指向 2.10.2 镜像;现在它写的是 2.11.1。

## 新设置

无。

## 升级

对 2.11.1 的镜像和图表做一次普通的 `helm upgrade`，或在你的 Quadlet 单元里换上新标签。如果你在 arm64 上，并且在 2.11.0 仅支持 amd64 期间留在 2.10.2，这就是你迁移到 case 结构编辑器、把选区转为子图、整理布局、命名连线、缩放到 400%、节点符号、面板对象设置器和图写入关卡的时机：阅读 2.11.0 的说明，了解它们是什么，以及哪些尚未得到证明。首次启动不会发生任何事，也无需迁移。

镜像：`ghcr.io/hotloop-io/hotloop-flow:2.11.1`，linux/amd64 和 linux/arm64。Chart：`https://hotloop.io/hotloop-flow/`。这个标签的 README 有其余内容，还配有图片：https://github.com/HotLoop-io/hotloop-flow/blob/v2.11.1/README.md
