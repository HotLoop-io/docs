## 这是什么

1.0.0 把身份和治理方面的工作以及一个新的编辑器放在同一个版本里。0.1.2 里的一切都还在,工作方式不变:引擎、连接器、导入器、Helm chart、Quadlet 单元和工作流文件格式。变化的是工厂能用一个实例做什么,以及做的时候它是什么样子。

我们把它叫作 1.0.0,是因为编辑器是我们在这个版本号下署名之前想要的最后一块拼图。每个界面都是对真实 API 工作的,下面的每个功能都是对它所连接的真实服务器测试过的,而不是替身。

## 新编辑器

它用 Astro 和 Svelte 岛重新构建,采用 HotLoop 自己的配色和字体,在你自己选择之前跟随系统的浅色或深色模式。它依然内置在二进制文件里,不会从任何地方获取内容,所以没有互联网的机器和有互联网的机器运行得一样好。旧编辑器的每个界面都在这里,功能照旧,画布也一样:我们是把它的代码搬过来,而不是重写,并在前后清点了每个界面、按钮、字段和 API 调用,确保没有遗漏。

你保存的 URL 仍然有效。`#/w/<id>`、`#/x/<id>`、`#/executions` 和调试链接会打开相同的界面,`/app/main.js` 和 `/app/main.css` 也仍然响应。

## 新增内容

SAML,已对 Keycloak 测试,只接受已签名的响应。LDAP 和 Active Directory,已对 OpenLDAP 和 Samba 域控制器测试,角色来自组。SCIM,已对 scim2-tester 测试,让提供商无需任何人操作界面就能创建和停用账户。自定义角色,由项目权限组成。OpenBao 或 HashiCorp Vault 中的外部密钥,凭据的密码存放在存储中并在那里轮换。把审计日志和已完成的运行流式输出到 syslog(TCP、UDP 或 TLS)和 OTLP,已对真实的 syslog 服务器和 Loki 测试。变量、文件夹、洞察、运行上的注释、脱敏策略,以及 S3 和 Azure Blob 存储,已对 Garage 和 Azurite 测试。

编辑器为它们各有一个界面:变量、洞察,以及设置下的角色、脱敏、外部密钥、日志流式输出,以及登录和 SCIM。每个人只会看到其角色允许的内容,其余的服务器仍然会拒绝。

## EmberOps 步骤已移除

我们移除了 EmberOps 连接器。九个步骤(`erpnext.trigger`、`getList`、`getDoc`、`create`、`update`、`delete`、`submit`、`cancel` 和 `call`)、"EmberOps 文档创建或更改时"触发器、EmberOps 凭据类型,以及提供它们的界面和文档,都不在 1.0.0 里了。如果需要访问 EmberOps,HTTP 步骤会用凭据调用它的 REST API,这个方式现在就能用。

用这些步骤保存的工作流不会被丢弃,也不会被悄悄修改。它无法通过验证,也无法启动,提示会指出该步骤并说明 EmberOps 步骤已在 1.0.0 中移除。删除这个步骤,或换成 HTTP 步骤,它就能再次运行。EmberOps 类型的凭据会留在你的列表中,不再使用,你可以删除它。导入器不再带入 EmberOps 节点,它会以停用状态进来,设置放在它的备注里,和任何没有对应步骤的节点一样。

## 从 0.1.2 升级

把 1.0.0 `helm upgrade` 上去,或者让 `:stable` 推进 Quadlet 单元。升级过程中会运行八个迁移(0018 到 0025)。它们为角色、变量、文件夹、注释、脱敏策略、SCIM、密钥提供商和日志目标创建表,并添加一列:工作流所在的文件夹。它们不会动你已有的内容,所以你的工作流、凭据和运行都在原处,密钥也仍然能打开它们。SAML、LDAP、SCIM 和 Blob 存储在你设置它们的 `HOTLOOP_CASCADE_*` 设置之前是关闭的,这些设置在 `docs/IDENTITY.md` 和 `docs/GOVERNANCE.md` 里。对一个一项都不设置的实例,什么都不会变,除非你的某个工作流用了 EmberOps 步骤(见上文)。

## 需要了解的事

迁移只会向前。回滚只是把旧镜像放回去,并不会撤销数据库的迁移,所以更新之前请先备份,并把备份当作回头的路。这些迁移不会更改或删除原有的内容,但我们没有在新架构上运行过旧镜像,所以不做保证。

外部密钥需要允许的路径。没有任何路径的提供商会被拒绝,这是有意的,因为存储的令牌通常能读到的内容,远多于编辑凭据的人应该能指名的范围。

SCIM 从不向提供商显示实例所有者,来自提供商的 DELETE 会停用并隐藏账户,而不是擦除,这样提供商就无法删除最后一个能登录的人。重新创建会带回同一个账户。

变量不是密钥。能读取项目的人就能读取它的变量,值在运行数据中不会被脱敏。密码请放在凭据或外部存储里。
