作为面板打开的画面(`/?screen=<name>`)现在在任何尺寸下都会铺满它的显示屏,Alarms 画面可以导入 CODESYS 报警文件,以及几项修复。只为 amd64 构建;多架构构建作为下一个版本跟进。

## 变更内容

- **面板页面铺满它的屏幕。** 在 1920x1080、1366x768 和 3840x2160 下,它覆盖整个显示屏,没有空白。它有带工厂名称的页眉、显示有多少设备在线的 Live 状态,以及带日期的 24 小时时钟。数字和仪表随屏幕变大,趋势的坐标轴和图例也一样。只有面板页面改变;仪表板保持原样,客户的卡片、尺寸和名称是他们自己的。
- **Alarms 画面导入 CODESYS 的 Export Alarms 文件。** 仅限管理员:选择设备,命名应用,选择文件,阅读会导入什么和不会导入什么的预览,然后导入。API 路由本来就有。
- **同一地址和端口上的 OPC UA PubSub 设备共用一个套接字。** 第二台设备永远无法绑定,而重用选项会在它们之间拆分发布者的数据报。
- **缓慢的应答不再堆积。** 比刷新还慢的摄像头卡片现在会显示它的画面,卡片和 UniFi 画面只在上一次应答之后才再次询问,曾失败过一次的发现批次会重试,而以主机名连接的 SNMP 设备保留它自己等待应答的时间。
- **核心产品采用 HotLoop Free Use License 1.0。** 更早的版本保留它们发布时所采用的条款。参见 NOTICE。
- chart 页面上的 **App Store 图标** 是 HotLoop 品牌标志。

## API 变更

无。

## 从 4.21.1 升级

普通的 `helm upgrade`。没有迁移,没有新的 secret,没有任何不能回滚的东西。

## 已测试

面板页面在测试中按上面三种尺寸做了检查,由 Emberburn 为一个 Gateway 提供数据。
