HotLoop Flow 2.11.0 让 FlowLab 更易于搭建,也更安全地向设备下达指令:一个真正的分支结构编辑器、把所选内容剪切成子图的方法、让连线远离节点的布局、命名连线、400% 缩放、每个图表节点上的符号、按名称设置面板对象的节点,以及只通过 HotLoop 的写入闸门向设备写入的节点。

## 新功能

- **分支结构编辑器。** 分支结构的各个分支是由分支名称和图表选择器组成的行,默认分支另有第二个选择器,不再是一个 JSON 框。指明循环或子图所运行的图表的属性也是一个选择器。选择器列出流程文件中的 FlowLab 图表。旧流程文件中手写的名称显示为对应的标签页,保存时存为它的 id,存储的值与以前是同样的 JSON。
- **所选内容转为子图。** 在图表中选中节点后,图表栏的**所选内容转为子图**会询问名称,并把它们剪切到一个单独的标签页,在原位置留下一个子图节点。输入和输出由穿过所选内容边缘的连线推算得出,这是一次可撤销的编辑,在您部署之前不会保存任何内容。
- **整理布局。** 标签栏的**整理布局**把图表排成列,使数据从左向右读取,给跨列的连线一条通道,并移开挡住连线绘制曲线的节点。它保留块的左上角,是一次可撤销的编辑。在一个 30 个节点的测试图表上,没有任何连线穿过节点。
- **连线名称。** 图表的连线在中间以它所来自的输出命名,声明了类型时显示在类型旁边。悬停时仍然显示它传送过的最后一个值。消息流的绘制方式和以前一样。
- **400% 缩放。** 画布围绕指针在 5% 到 400% 之间缩放。
- **符号。** 每种 FlowLab 节点类型都在其主体中间画有我们自己的符号,位于文字标签旁边。它们是为 Flow 绘制的简单线条,不是图标字体,也不是别人的作品。
- **按名称设置面板对象。** `dia-panel-set` 在图表运行时,按标签或 id 更改控件或指示器的 `visible`、`enabled`、`color`、`label`、`min` 或 `max`。被禁用的控件会拒绝操作员的设置,被隐藏的对象不会绘制,操作员打开的面板会随之更新。与任何对象都不匹配、或匹配多个对象的名称,在节点上输入时是部署时的问题,通过连线传入时是连线上的错误。运行从设计时的面板开始。
- **图表写入闸门。** `dia-hotloop-write` 通过 HotLoop 的写入闸门,把它的值写入 HotLoop 中的变量(`device/tag`),闸门判定写入已开启、变量已布防、值在范围内。HotLoop 记录每一次尝试,无论是否被拒绝,原因为 `flow:<diagram>/<node id>`。拒绝是节点错误连线上的错误,附带闸门自己的原因(错误代码 5006),无法连接 HotLoop 时也是如此;两种情况下写入都不会发生。未选择 HotLoop 时,节点拒绝部署,所以它绝不是绕过闸门的办法。

## 变更内容

- **闸门的范围,按发布时的样子。** Flow 的原始串口和仪器节点(`dia-serial-write`、`dia-instr-query` 等)尚未经过闸门。它们与万用表、电源和负载这类台式仪器通信,这些仪器在 HotLoop 中没有变量,所以 `dia-hotloop-write` 不涵盖它们。向工厂网络上的设备下达指令的图表使用 `dia-hotloop-write`,在下一个版本之前,图表仍可直接驱动仪器。接下来是每台仪器的写入开关,默认关闭:在拥有相应权限的人打开某台仪器的写入之前,没有任何图表会驱动电源、耐压测试仪或任何仪器输出,读取则保持开放。
- 其他方面与 2.10.2 的行为没有不同。2.10.2 的流程文件逐字节加载和保存。

## 新设置

`dia-hotloop-write` 接受一个 `hotloop` 连接和一个 `tag`。`dia-panel-set` 接受一个 `target` 和一个 `property`。case 编辑器和图选择器保存的属性与之前相同。

## 升级

只需对 2.11.0 的镜像和 chart 执行一次 `helm upgrade`,或在您的 Quadlet 单元里换上新标签。首次启动时不会发生任何事,也不需要迁移。此版本先发布 amd64,arm64 构建随 2.11.1 跟上,所以 arm64 机器在此之前留在 2.10.2。

镜像：`ghcr.io/hotloop-io/hotloop-flow:2.11.0`，先发布 linux/amd64，arm64 在 2.11.1 中跟进。Chart：`https://hotloop.io/hotloop-flow/`。这个标签的 README 有其余内容，还配有图片：https://github.com/HotLoop-io/hotloop-flow/blob/v2.11.0/README.md
