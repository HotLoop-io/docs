HotLoop Flow 2.7.0 是 FlowLab 的首个版本，是为试验台和数据记录器运行标签页的第二种方式。流程的运行与之前完全一样，你今天拥有的流程文件按字节加载和保存。FlowLab 只在你为它添加标签页时才会启动，所以如果你不添加，对你唯一的变化就是会话修复，也就是下面的最后一项。

## 新功能

**FlowLab 图。** 图是这样一个标签页：每个节点在每个连线的输入都有值时运行一次，互相之间没有连线的两个节点同时运行。用子流程按钮旁边新的 FlowLab 按钮添加一个。它会在画布上方得到一个带运行和停止的栏，它绘制的一切都在连线上：运行后每条连线的最后一个值、任何连线上保留最后 100 个值的探针，以及节点或连线上的断点。暂停、单步进入、单步跳过和单步跳出按节点工作，高亮执行会把运行放慢到足以跟上，并在十分钟后自动关闭。任何调试都不会改变一次运行的行为，并且有一个测试检查带探针的运行与不带探针的运行在每条连线上以相同的值结束。

**盒子里有什么。** 在一次循环到下一次循环之间传递值的 while 和 for 循环、基于计数或数组的 for 循环，以及错误连线：收到错误的节点什么都不做并把它传下去，连入循环的错误会让循环停止，并在循环的错误输出上附上来源和代码。`after` 连线决定两个不共享数据的节点的顺序。节点面板新的 FlowLab 部分有 21 种节点类型：常量、数学、比较、逻辑、等待、打包、字段、构建数组、两种循环及其循环体输入和输出、带读写的串口、读数解析器、稳定值检测器、写入文本文件的日志，以及面板用的控件、指示器和图表。docs/diagrams.md 有每一种的说明。

**操作员可以在手机上打开的面板。** `/panel/<diagram id>` 像编辑器一样登录，并在运行进行时显示图的控件、指示器和图表。图表保留最后 1,024 个点，除非你更改，并统计它放掉的点数。控件在服务器上按其类型、范围和选项检查，谁设置了它会记入审计日志。

**拔掉线缆也能挺过去的串口。** 什么都没读到的读取，或消失的端口，是错误连线上的一个故障。下一次读取会每秒尝试重新打开端口一次，并统计丢失和恢复。`examples/diagram-scale-logger` 中的示例读取一台秤，解析重量和单位，在最近五次读数一致时提示，在面板上用趋势图显示一切，并追加到 CSV 文件。在标签页上设置 `autostart`，它无需打开任何浏览器就能运行，每次部署后也会再次运行。

**新的 API。** `GET /diagrams`、`GET /diagrams/{id}`，以及用于 `run`、`stop` 和 `debug` 的 `POST`，用于 `controls/{node}`、`breakpoints` 和 `probes` 的 `PUT`。读取需要 `status.read`。运行、停止、设置控件和调试需要一项新权限 `diagram.run`，每一项都会连同操作者记入审计日志。

**读取失败不再覆盖会话。** 存在但无法读取的会话文件、I/O 错误或启动较晚的卷，不再会被下一次登录替换，JSON 无法读取的文件会保留在原文件旁边，而不是丢失。

## 变更内容

- 带有 `ew_diagram` 的标签页不参与消息运行时。其他所有标签页照旧运行。新的键是标签页上的 `ew_diagram` 和节点上的 `ew_in`，两者都能熬过往返，两个新测试和旧测试都检查这一点。
- README 写的是 79 种节点类型和“大约 36,000 行 Go”，两者都已过时。现在它写的是消息用 79 种节点类型，FlowLab 用 21 种。
- HotLoop MCP 客户端节点的测试现在通过 HotLoop 的关卡写入，因为 HotLoop 出厂时就开启了它的 MCP 写入。
- 一次部署会重启每个图的运行，即使是它没有改动的图。
- FlowLab 给二进制增加了约 370 KB，是在一台机器上前后测得的。二进制为 41.4 MB，amd64 镜像为 45.34 MB。
- README 的图片为新按钮和节点面板的新部分重新拍摄了。

## 新设置

无。权限 `diagram.run` 是新的。权限列表为 `["*"]` 的用户拥有它。拥有明确列表的人可以用 `status.read` 读取图及其面板，在你添加 `diagram.run` 之前不能运行图。

## 升级

在 amd64 上，对 2.7.0 的镜像和图表做一次普通的 `helm upgrade`；在 arm64 上，保持现状直到 2.7.1，或使用你的 Quadlet 单元里的新标签。首次启动不会发生任何事，没有需要迁移的内容，你的流程、部署记录和凭据都不会被触及。如果在保存了含图的流程文件之后回滚，旧版本会逐字节保留该文件，并对每个 FlowLab 节点显示 `unknown node type`，这些节点随后不会运行。我们已对照这个版本之前的构建检查过。

镜像：`ghcr.io/hotloop-io/hotloop-flow:2.7.0`，仅限 linux/amd64。我们先构建 amd64，让它在生产中被确认为稳定，然后一个别无他物的小版本 2.7.1 加上 arm64。在那之前，`2` 标签指向新的 amd64 镜像和 2.6.0 的 arm64 镜像，所以跟随 `2` 或 `2.6` 的 arm64 机器保持它现有的版本，固定在 `2.7.0` 的机器需要 amd64。图表：`https://hotloop.io/hotloop-flow/`。此标签的 README 有其余内容，附图片：https://github.com/HotLoop-io/hotloop-flow/blob/v2.7.0/README.md
