HotLoop Flow 2.10.1 就是加上 arm64 镜像的 2.10.0，别无其他。2.10.0 只发布了 amd64，以便先到达生产环境并被确认为稳定，它做到了：一家工厂运行了它一个多小时，没有重启。这是构建两者的那个小版本升级。代码、图表、设置和你的流程都没有变化。

## 变更内容

- 镜像为 linux/amd64 和 linux/arm64 构建。`2.10.1`、`2.10` 和 `2` 标签都包含两者。
- README 和安装页面写明 2.10.1,并说明支持 amd64 和 arm64。

## 新设置

无。

## 升级

对 2.10.1 的镜像和图表做一次普通的 `helm upgrade`，或在你的 Quadlet 单元里换上新标签。如果你在 arm64 上，并且在 2.10.0 仅支持 amd64 期间留在 2.9.1，这就是你迁移到 FlowLab 的仪器、case 结构、波形、共享记录类型、子图和日志轮转，迁移到能列出、读取、部署和回滚流程的 MCP 工具，以及迁移到防止持久 MQTT 输出在重新连接后把一条消息发送两次的修复的时机：阅读 2.10.0 的说明，了解它们是什么，以及哪些尚未得到证明。首次启动不会发生任何事，也无需迁移。

镜像：`ghcr.io/hotloop-io/hotloop-flow:2.10.1`，linux/amd64 和 linux/arm64。Chart：`https://hotloop.io/hotloop-flow/`。这个标签的 README 有其余内容，还配有图片：https://github.com/HotLoop-io/hotloop-flow/blob/v2.10.1/README.md
