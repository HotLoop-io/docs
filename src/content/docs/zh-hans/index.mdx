## 产品家族

HotLoop 是面向工厂现场的八款产品：四款随站点一起成长（IoT、Edge、Gateway 和 Edge Relay），另有负责逻辑编排的 Flow、负责工作流的 Cascade、为 PLC 自带画面而做的 HotLoop for CODESYS，以及把 PLC 数值送上网络的 Transmitter。 它们分五条发布线出货，所以每条线都有自己的版本。侧边栏的每个部分只显示该产品出货的内容，较大的产品会链接到它从较小产品继承的页面。

## 如何阅读这份文档

**“已验证”表示它在真实对象上运行过：**真实的 OPC UA 服务器、真实的代理、Ignition 本身，以及物理硬件上的真实设备。这是这些页面里每一项说法的标准，所以当页面说某个协议或功能可用时，它是跑过的。

**最新发布的版本就是您安装的版本。**描述比已发布版本更新内容的页面，会带有**下一版本**徽章和顶部的提示框，让您始终知道安装里有什么、接下来会有什么。
